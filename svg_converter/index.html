格式限制與使用提醒

支援內嵌的 SVG SMIL 動畫（animate、animateTransform）與常見 CSS 動畫；複雜的濾鏡、路徑變形、外部字型或其他動畫語法不保證每款都能正確轉換。

影片輸出取決於目前瀏覽器支援的 MediaRecorder 編碼，尤其 MP4 並非所有手機都可輸出。轉檔時請讓分頁保持前景，不要鎖定螢幕。

為了避免假動畫，若輸出影格全部相同、但原圖明明包含動畫，GIF 與影片匯出會停止並顯示原因。詳細驗收方式請見 ZIP 內 README。
