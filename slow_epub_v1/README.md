# 慢 慢 | EPUB 製作器（v1.1）

專為手機寫小說的作者製作。這是一個純前端靜態網站，無需伺服器資料庫，也沒有把小說內容上傳到任何服務。

## 使用方法

1. 把整個資料夾上傳到支援 HTTPS 的靜態網站空間，例如 Cloudflare Pages 或 GitHub Pages。
2. 用手機瀏覽器開啟 `index.html` 對應的網址。
3. 點「新增書籍」，設定書名、作者與封面（可稍後填）。
4. 展開「貼上文字／匯入 TXT」，從 Samsung Notes 貼上文字，或選擇 TXT 檔案。
5. 選擇「自動辨識章節並匯入」或「原樣新增成一頁」。
6. 點選各章「編輯」，修改文字、標題、縮排等；完成時按「儲存」，按「取消」可放棄本次修改。新增番外、版權頁、後記也一樣。
7. 如需翻頁時可看見的目錄，勾選書籍畫面的「匯出時自動產生目錄內頁」；原本的閱讀器導覽目錄仍會自動提供。
8. 按「匯出 EPUB」，會產生繁體中文、橫排、流動版面的 EPUB 3 電子書。

## 初版功能

- 直接輸入文字、貼上原稿、匯入 UTF-8 / Big5 TXT。
- 辨識「第一章」「第二章」「Chapter 1」「番外」「後記」等獨立標題行，自動切章。
- 游標所在行手動切章；章節與內頁獨立編輯、上下調整順序、刪除、選擇是否列入 EPUB 目錄。
- 封面 JPG / PNG、書名、作者、語言、出版者、簡介、版權欄位。
- 各章獨立設定縮排、對齊、行距、段距；預覽每章排版。
- 全書搜尋、整本書的純文字取代。
- IndexedDB 本機自動暫存書籍資料與已儲存的章節、多本書獨立管理，以及 JSON 專案備份與還原。
- 每次開啟章節都有獨立編輯狀態：儲存才套用，取消就還原；新增後取消也不會留下空白章節。未按儲存就關閉網頁的章節修改不保留。
- 可勾選自動產生可見的目錄內頁，連結隨章節順序／標題／列入目錄設定更新。
- 純 JavaScript 產生 EPUB 3 ZIP，ZIP 內第一筆是未壓縮的 `mimetype`；無第三方程式庫。

## 注意事項

- **不能直接以手機的 `file://` 路徑開啟並期待可靠的暫存。** 不同手機瀏覽器可能限制本地頁面的 IndexedDB。請部署到 HTTPS 網址，並定期匯出專案備份。
- 自動暫存存在「目前瀏覽器」的 IndexedDB，並非雲端同步。清除網站資料、換手機、無痕模式，都可能使暫存失去。
- 修改章節時不會即時寫入專案，須按「儲存」確認；「取消」不保留任何這次的變更。請勿在未儲存時直接關掉瀏覽器。
- 原始文字中的換行、全形空格、半形空格保留在可編輯的專案裡。輸出時若選 CSS 縮排或不縮排，僅針對 EPUB 排版去除行首空格，不會覆寫原稿。
- EPUB 是流動排版格式，不同閱讀器可能覆蓋字體、行距或排版樣式。
- 本版專注純文字小說：**不支援 DOCX、已存在的 EPUB 匯入、局部粗體／斜體、書內插圖、腳註、直排**。
- 本工具的 ZIP 產生器使用合法的 STORE 無壓縮方式，檔案可能比壓縮版 EPUB 稍大，但不影響 EPUB 3 規格。
- 本版輸出以 EPUB 3 和 Readmoo 所偏好的無腳本、XHTML、英文資源檔名為目標；**不能保證直接通過讀墨上架審核**。正式上架前仍應以 EPUBCheck、mooPub 驗證工具檢查並在閱讀器試讀。
