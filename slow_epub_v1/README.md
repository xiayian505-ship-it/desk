# 慢 慢 | EPUB 製作器（v1.6）

專為手機寫小說的作者製作。這是一個純前端靜態網站，無需伺服器資料庫，也沒有把小說內容上傳到任何服務。

## 使用方法

1. 把整個資料夾上傳到支援 HTTPS 的靜態網站空間，例如 Cloudflare Pages 或 GitHub Pages。
2. 用手機瀏覽器開啟 `index.html` 對應的網址。
3. 點「新增書籍」，設定書名、作者與封面（可稍後填）。
4. 展開「貼上文字／匯入 TXT」，從 Samsung Notes 貼上文字；也可以一次多選 TXT 檔案。
5. 已分章的 TXT 可直接按「批次匯入所選 TXT（各檔一章）」；工具會依檔名自然排序、去除 `.txt` 作為章名，各檔獨立新增章節。若只選一個 TXT，仍會顯示在下方文字框中，可使用原本的「自動辨識章節並匯入」或「原樣新增成一頁」。
6. 點選各章「編輯」，修改文字、標題、縮排等；完成時按「儲存」，按「取消」可放棄本次修改。新增番外、版權頁、後記也一樣。若要章／節目錄，點上層旁的「＋ 子節」，或新增「目錄分類」後再放子節。
7. 如需翻頁時可看見的目錄，勾選書籍畫面的「匯出時自動產生目錄內頁」；原本的閱讀器導覽目錄仍會自動提供。
8. 展開「目錄樣式與即時預覽」，可調文字顏色、字級、行距、章節間距、縮排、對齊、連結底線或自訂 CSS。下方直接預覽目前章節名稱，點選預覽章名可確認跳轉目標；可按「恢復預設目錄樣式」。
9. 如要在章節加入插圖，開啟該章編輯頁的「本章插圖」，選 JPG／PNG，再選「正文游標所在行之後」「章首」或「章尾」，按「插入圖片」。正文會多一行 `[[slow_image:...]]` 插圖標記；這一行代表圖片所在的位置，可以連同段落移動，但不要拆掉。插入後可設定寬度（60%、80%、100%）、替代文字、圖說，以及是否獨立一頁。若要一整頁純插圖，可新增「內頁」，將圖片插入章首。
10. 章節編輯頁按「儲存」，圖片才會連同正文一起存入目前專案；按「取消」不會保存本次插圖操作。已存插圖也會跟著 JSON 專案備份一起匯出，之後還原仍可編輯。
11. 按「匯出 EPUB」，會產生繁體中文、橫排、流動版面的 EPUB 3 電子書。

## v1.6：由閱讀器統一字型

- 匯出 EPUB 3 時，書籍共用樣式 `OEBPS/styles/book.css` 不再指定 `font-family: serif`；目錄專用樣式 `OEBPS/styles/toc.css` 同樣移除這個指定。章節標題、正文、閱讀須知、後記與附錄都沿用閱讀器所決定的字型。
- EPUB 目錄預覽不再強制套用 serif。製作器編輯文字區仍保留工具本身的排版字型；預覽不代表每個閱讀器最終選擇的字體。
- **不用設定書籍字型，也不內嵌字型檔**。閱讀器的「字體」設定可自行選明體、黑體等；部分閱讀器可能對特殊符號、缺字、導航目錄或標題另行處理，無法保證所有閱讀器顯示完全相同。
- 進階「自訂目錄 CSS」若使用 `font-family` 或 `font` 指定字型，仍可能覆蓋閱讀器選擇；為維持一致，請避免自行設定。
- v1.5 的章節階層、純分類目錄、圖片插入、JSON 備份與舊專案相容性均保留；**舊 EPUB 不會自動變更**，必須以本版重新匯出。

## v1.5：章／節階層與目錄分類

- 在章節列表點某一上層章節旁的「＋ 子節」，即可新增從屬內容。亦可在編輯頁的「隸屬於哪個上層」調整階層。
- 「＋ 目錄分類」可建立只有目錄名稱、沒有獨立正文頁的群組，例如「後記」。再點其「＋ 子節」，建立「專業名詞」「作者遺言」等項目。
- EPUB 3 的閱讀器目錄 `nav.xhtml` 和可選的書內目錄頁，都會輸出真正的巢狀 `<ol>`。上層一般章節可點選，只有分類名稱的群組不會產生空白正文頁。
- 最多兩層（章／節）。在列表按上下鍵，上層章節會連同所有子節一起移動；子節只在同一上層內移動。刪除上層時子節會保留並提升為最上層。
- v1.4 或更早的專案與 JSON 備份可直接開啟，既有章節預設都在最上層；插圖、縮排、章節內容都不會被修改。

## 功能

- 直接輸入文字、貼上原稿、匯入 UTF-8 / Big5 TXT。
- **v1.4：支援書內插圖（JPG／PNG）**，包含章首、章尾、正文指定行後，及以「新增內頁」製作獨立插圖頁。可設定縮放寬度、替代文字、圖說、閱讀器支援時的換頁要求；圖片實體加入 EPUB `OEBPS/images/`，並登記於 OPF manifest，不依賴外部網址。
- 書內插圖使用單獨的文字標記定位，不會被原稿新增段落推移定位；插圖和封面都會隨 IndexedDB 專案與 JSON 備份保存，並支援取消修改、刪除、編輯與預覽。缺圖、重複定位或未放入正文的圖片在匯出前會明確報錯，避免默默漏圖。
- **v1.3：一次選取多個 TXT 批次匯入**，每個檔案建立獨立章節（檔名去副檔名為章名）；依檔名自然排序，如 `2.txt` 在 `10.txt` 前面，亦支援 `第二章.txt` 在 `第十章.txt` 前面。保留檔案正文空白與換行，追加到現有章節之後，不覆蓋、不重複切章。
- 批次匯入採全部讀取成功才寫入書籍的方式，遇到非 TXT 或編碼錯誤時不會加入一半章節。多選檔案不會取代文字貼上框原本的內容。
- 辨識「第一章」「第二章」「Chapter 1」「番外」「後記」等獨立標題行，自動切章。
- 游標所在行手動切章；章節與內頁獨立編輯、上下調整順序、刪除、選擇是否列入 EPUB 目錄。
- 封面 JPG / PNG、書名、作者、語言、出版者、簡介、版權欄位。
- 各章獨立設定縮排、對齊、行距、段距；預覽每章排版。
- 全書搜尋、整本書的純文字取代。
- IndexedDB 本機自動暫存書籍資料與已儲存的章節、多本書獨立管理，以及 JSON 專案備份與還原。
- 每次開啟章節都有獨立編輯狀態：儲存才套用，取消就還原；新增後取消也不會留下空白章節。未按儲存就關閉網頁的章節修改不保留。
- 可勾選自動產生可見的目錄內頁，連結隨章節順序／標題／列入目錄設定更新。
- 目錄樣式獨立儲存：預設文字黑色、沒有藍色超連結或底線；可調整基本格式、自訂 CSS、即時預覽及一鍵恢復預設。
- EPUB 中的目錄樣式獨立存於 `OEBPS/styles/toc.css`，僅套用 `nav.xhtml`，不影響小說章節或閱讀器內建目錄；目錄及正文均不指定字型。
- 純 JavaScript 產生 EPUB 3 ZIP，ZIP 內第一筆是未壓縮的 `mimetype`；無第三方程式庫。

## 注意事項

- **不能直接以手機的 `file://` 路徑開啟並期待可靠的暫存。** 不同手機瀏覽器可能限制本地頁面的 IndexedDB。請部署到 HTTPS 網址，並定期匯出專案備份。
- 自動暫存存在「目前瀏覽器」的 IndexedDB，並非雲端同步。清除網站資料、換手機、無痕模式，都可能使暫存失去。
- 修改章節時不會即時寫入專案，須按「儲存」確認；「取消」不保留任何這次的變更。請勿在未儲存時直接關掉瀏覽器。
- 原始文字中的換行、全形空格、半形空格保留在可編輯的專案裡。輸出時若選 CSS 縮排或不縮排，僅針對 EPUB 排版去除行首空格，不會覆寫原稿。
- EPUB 是流動排版格式，不同閱讀器可能覆蓋字體、行距或排版樣式。尤其閱讀器內建側邊目錄由 App 控制，這裡不能改它的外觀。
- 自訂 CSS 請使用 `#toc` 下的選擇器，例如 `#toc a` 或 `#toc li`；為使 EPUB 完全離線使用，禁止 `@` 規則、`url()` 與外部資源。預覽 CSS 與匯出的 CSS 共用，但實際顯示仍可能因閱讀器不同而有差異。
- 既有 v1.1、v1.2 專案不必轉檔，未設定過目錄樣式的舊資料會自動使用新版預設。
- 本版以文字小說與簡單書內插圖為主：**不支援 DOCX、既有 EPUB 匯入、局部粗體／斜體、圖文環繞、腳註、直排**。圖片置中且與正文分段，不提供任意拖拉或文字繞圖。
- 插圖僅支援真實的 JPG／PNG，每張最多 8 MB；大量照片可能造成 EPUB／JSON 備份檔案很大，或使瀏覽器 IndexedDB 達到儲存上限。請保管原始圖片並定期下載備份。
- 插圖「獨立一頁」透過 EPUB CSS 的換頁屬性要求閱讀器換頁；實際能否單獨佔一頁會依閱讀器版本而不同，不是固定版面書籍。
- 如果手動刪除文字中的 `[[slow_image:...]]` 標記，圖檔仍留在章節清單；請用「插入游標處」把它放回正文，或「移除圖片」將它刪掉。匯出時會阻止未定位圖檔失蹤。
- **原本 v1.3／v1.4 的舊專案可直接開啟**，不必轉檔；沒有插圖的章節會自動視為空插圖清單。
- 本工具的 ZIP 產生器使用合法的 STORE 無壓縮方式，檔案可能比壓縮版 EPUB 稍大，但不影響 EPUB 3 規格。
- 本版輸出以 EPUB 3 和 Readmoo 所偏好的無腳本、XHTML、英文資源檔名為目標；**不能保證直接通過讀墨上架審核**。正式上架前仍應以 EPUBCheck、mooPub 驗證工具檢查並在閱讀器試讀。
