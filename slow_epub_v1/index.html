章節與內頁

目錄內頁會放在正文之前，依勾選「列在 EPUB 目錄中」的章節自動更新，點選名稱即可跳轉。

目錄樣式與即時預覽

這裡只調整書內可翻閱的「目錄內頁」，不會改變閱讀器側邊欄的目錄外觀。

請用 #toc、#toc h1、#toc ol、#toc li、#toc a 等選擇器；自訂 CSS 會排在基本設定之後。為避免外部資源，禁止 @ 規則與 url()。

以下直接預覽目前章節的目錄效果。點章名會顯示對應的跳轉目標，實際閱讀效果仍以閱讀器為準。

各章可單獨編輯；上下移動可調整 EPUB 閱讀順序。

全書搜尋與取代
