# 慢慢終端機 v1

將 ZIP 解壓後的 `sbs_termux/` 整個資料夾覆蓋原資料夾。舊版不再使用，建議覆蓋前先移除舊資料夾，避免遺留舊檔。

- `index.html`：主頁；`group.html`：共用分類頁。
- `sbs_termux.css`：功能樣式；`sbs_termux_style.css`：版面樣式；`css/`：分類頁與輸出框樣式。
- `js/`：依責任拆分的功能模組；`commands/`：依指令類型拆分的資料。
- 專案與目前專案使用 `sbs_termux_v1` localStorage 前綴；選取清單用 sessionStorage 跨頁暫存，重新整理清空；產生結果不儲存。
- 最多選取 5 個指令項目；產生後可逐條或全部複製。
- 網站只產生文字，不執行 Termux 指令。Git push / pull / add 等操作請先確認目標、分支與檔案。
- 軍火庫零件均透過公開 HTTPS 絕對路徑載入：`ui/clipboard/clipboard_copy.js`（複製）、`ui/toast.js` + `ui/toast.css`（提示）、`ui/responsive.css`（基礎響應式）。`js/clipboard.js` 與 `js/toast.js` 只做本專案的參數驗證、呼叫與訊息介面，不複製軍火庫實作，也不修改軍火庫。需網路連線。

## 驗收建議
1. 建立專案，檢查目前專案與路徑；點「建立目錄 → 加入選取」。
2. 在「全部指令」選一條，再進「指令分類」的另一類選一條，檢查選取清單跨頁保留。
3. 選滿 5 條，確認第 6 條不能加入；移除後可以再加入。
4. 產生指令，逐條與全部複製；切換專案後產生結果應清空。
5. 重新整理，確認選取清單清空，但專案清單仍保留。

## 程式碼與預留分頁規則

- HTML 與 JavaScript 採用可閱讀的換行及縮排，依責任分檔，不把不同功能壓成單行。
- 「慢慢看一下」為完全空白的預留分頁；專案管理、指令選取和產生框只在工作分頁顯示。
- 軍火庫函式仍以 `https://lib.stillnessbyslowly.com/` 的絕對網址引用，不複製到本專案。
