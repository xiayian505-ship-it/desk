# 慢慢封面｜《日新月異》設計記錄（Social v0.1）

> 中文名：**日新月異**｜英文代號：`social`｜首頁分類：**S**  
> 資料夾：`cover/social/`  
> 預設藝術字：**《星火燎原》**，接入層 code **`ember`**  
> 雙槽預設：**A「日新月異」／B「交友不慎」**，所有文字區域一致。

## 一、選擇社群貼文的理由

此款不是從電視新聞、播報卡片或跑馬燈改造而來，而是以**帶圖片的社群貼文**為辨識原型。最初擔心和 `news`（《飛鴿傳輸》）同樣是「圖片＋文字」而看起來相似；後來決定以社群貼文專屬的結構區別：**頭像圖片框、帳號資訊、兩排貼文正文、發文圖片，以及愛心／留言／轉發互動列**。這些社群使用習慣帶來的視覺辨識，比另加新聞資訊條更自然。

這也讓「慢慢封面」首次正式讓同一款模板使用**兩個獨立圖片框**，而不是前三款都只用一框。系統從一開始就容許 N 個圖片框；因此這次直接使用既有共用能力，沒有為 `social` 另外撰寫圖片上傳／合成控制器。

中文名《日新月異》呼應貼文與話題快速更替；「交友不慎」帶來詼諧的社群經驗反差。預設《星火燎原》則聯想到話題「炎上」、社群討論與火焰。**這些是作者命名、配字與選款時的設計理由，不是限制使用者只能創作這一種題材。**

## 二、文字區域：三組、每組 A/B，共六槽

| 區域 | A 預設 | B 預設 | 版面用途 |
| --- | --- | --- | --- |
| **帳號資訊**（較小） | 日新月異 | 交友不慎 | 與左上頭像相鄰，上下兩段仿帳號資訊。 |
| **貼文第一排**（較大） | 日新月異 | 交友不慎 | 第 1、2 槽水平排列成第一行。 |
| **貼文第二排**（較大） | 日新月異 | 交友不慎 | 第 3、4 槽水平排列成第二行。 |

作者原話：**「2 的文字槽，我想放 4 個，1.2／3.4，這樣才更像社群。」** 因此正文不是只有單一 A/B 區，而是**兩組獨立 A/B，視覺呈現兩行**。帳號資訊再使用一組 A/B，合計六個可分別輸入與選款的藝術字槽。所有六槽都預設《星火燎原》 `ember`，文字只需想兩種：**A 永遠先填「日新月異」，B 永遠先填「交友不慎」**。使用者之後可自行分別改字、換款；不能因為預設相同就把六槽合併成兩個不可獨立編輯的物件。

每槽仍遵守既有 **1～4 字**的限制。文字內容都由藝術字接入層生成為 SVG，**不**由本款 `social_visual.js` 寫死。

## 三、兩個獨立圖片框

1. **`social-avatar`**：左上小圖片框，位置靠近帳號資訊，供使用者上傳頭像。共用合成器原生用矩形嵌圖；本款 `social_visual.js` 在框上以 SVG `evenodd` 遮罩遮住四角，顯示成圓形頭像（白色卡片底為固定視覺紙色），因此不改動其他模板圖片框或共用層。
2. **`social-post`**：貼文正文下方的大型圖片框，是主要插畫／照片區。保留完整可上傳圖片的長方形畫面；不用預設照片取代使用者自己的圖。

兩框具有**不同 ID**，背景與圖片各自獨立設定，也能各自移除；直版和橫版保留同一組 ID，使切換方向後可以沿用已選圖片。兩框預設只是淺灰底色，不是嵌入的照片。整張封面的背景仍可透過共用 UI 改成單色、撞色、漸層、透明或底圖。

頭像的白色四角遮罩屬於**Social 單款視覺**，而非通用「圖片框自動變圓」；若日後更換整張封面背景，頭像角落仍會保持白色社群卡片區域。需要調整時只改本款視覺檔即可。

## 四、SVG 互動列：不是可點的按鈕

底部固定畫出三組互動資訊：

- **實心愛心**＋**99**（不是只有心形外框）。
- **留言氣泡**＋**99**。
- **轉發雙箭頭**＋**99**。

圖示全部由 `social_visual.js` 的 SVG 向量路徑繪製，不使用外站圖示、貼圖、任何特定社群平台的商標／Logo。**「99」也是本版指定的固定示意數字**，由 SVG 的文字元素呈現，屬於社群貼文外觀裝飾，**不是** A/B 藝術字槽、使用者即時按讚數或可互動的計數器。若以後想改數字或圖示形式，應只改 Social 專屬視覺檔，不能擅自增加共用 UI 的功能或數字欄位。

其他固定裝飾只包含卡片圓角細框、分隔線、右上三點更多符號與圖片框細邊；不預設帳號名稱、平台 Logo、發文日期、固定小說文字等額外內容。

## 五、直式與橫式：各有獨立座標

### 直式（840 × 1200）

- 頭像 `social-avatar`：`(77,78,96,96)`；其右側上下排列較小的帳號 A/B。
- 第一排正文：A 與 B 在 `y=227`；第二排正文：A 與 B 在 `y=339`。
- 大圖 `social-post`：`(75,473,690,548)`，直式圖片區足夠大，方便放人物與小說插畫。
- 下方留出互動列：愛心、留言、轉發，各搭配固定 `99`。
- 卡片外框 `34,34,772,1132`，白色社群卡面與細灰線，不沿用 News 的色塊或跑馬燈。

### 橫式（1200 × 840）

- 頭像 `social-avatar`：`(84,54,95,95)`，帳號 A/B 改用橫向較寬的區域。
- 第一排正文：A/B `y=193`；第二排正文：A/B `y=287`。
- 大圖 `social-post`：`(81,386,1038,333)`，是為橫式重新安排的橫幅畫面，不是把直式旋轉 90°。
- 互動列依橫式寬度重新分散到下方，而不是沿用直式的三組座標。

這款為保留「頭像／文字／圖／互動」自然閱讀順序，兩方向都使用上下式社群卡片結構；但圖片比例、文字槽位置及互動圖示的配置分別定義。

## 六、共用能力與獨立設計的界線

本版沿用既有：

- `cover/shared/cover_workbench*` 的三個設定分頁、A/B 槽、選款、背景與兩框各自上傳／移除圖片、直橫切換自動預覽、匯出與 Loading。
- `cover/shared/word_fit.js` 的可見範圍縮放。
- `cover/news/bridge/` 中現有的共用藝術字接入層（`ember` **已收錄，無需另外上傳藝術字原始 Repo**）。
- `cover/news/runtime/cover_composer.js` 的多框合成、原始 SVG 向量、PNG 與直式 700×1000 書封 PNG。

**本款排版和 SVG 視覺絕不共用其他封面的專屬布局。** `social_layout.js` 和 `social_visual.js` 都只供 `cover/social/` 使用。以後修改 News、Textbook、Joker 的視覺或槽位，Social 不會跟著變；反過來也相同。共用的是**能力**，不是**設計參數**。
