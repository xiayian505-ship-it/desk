# 慢慢封面｜《旗開得勝》設計記錄（Billboard v0.6）

> 中文：**旗開得勝**｜英文代號：`billboard`｜首頁字母：**B**  
> 位置：`cover/billboard/`  
> 預設藝術字：**《投我一票》**（接入代號 `ballot`）  
> 唯一兩組預設文字：**A「旗開得勝」／B「不得不投」**，重複於上下兩組。

## 一、最初的構想

以**台灣路邊常見的候選人看板**作為小說封面載體；要求不是抽象「選舉風」，而是讓人**一眼看出是候選人看板**。大幅人物照、醒目文字、投票符號就是關鍵元素。右側人物圖是一個獨立可上傳的圖片框，左側文字全部由可編輯的藝術字槽構成。

命名為《旗開得勝》，搭配「不得不投」，屬於原創小說封面的幽默設定，**不對應任何真實候選人或政黨**。藝術字《投我一票》與看板主題呼應。

## 二、文字版型（v0.5 起沿用）

**總共只有四個槽：左欄大主槽上下各一個、右欄小副槽上下各一個。** 上下兩組 A/B 分別獨立編輯和選款。**四槽全為直排**，直版、橫版都一致，不旋轉成橫排。

```text
    左欄大主槽      右欄小副槽
        A1             B1
        A2             B2
```

第一組與第二組的文字預設皆為：

- A 主槽：**旗開得勝**（候選人姓名的角色）
- B 副槽：**不得不投**（政見／口號的角色）

### 關鍵修正：緊密不等於重疊

作者實際把藝術字從《投我一票》換成其他款式後發現：**有些字會疊在一起**。原因不是作品選錯，而是 v0.4 的槽矩形本身就互相重疊：直版上、下主槽重疊 63 SVG 單位，橫版重疊 30 單位；左右 A/B 的矩形也互相重疊。預設款剛好沒那麼明顯，換款就暴露問題。

v0.5 改成：

- **左欄 A 大、右欄 B 小；每欄上下各一個；全部直排**。
- 同一排 A/B **矩形剛好接觸但不互相覆蓋**。A 採靠右、B 採靠左的排版，讓字的主體視覺上盡可能靠近。
- 上下兩組**留極小的安全間隙**，而不是讓 SVG 畫布互相跨入；各款藝術字本身的裝飾、字形有所不同，也應先保障四槽獨立。
- **仍不增加任何文字分隔線或灰色橫條**；背景、圖片框、圈選章都不動。
- 本款 `billboard_layout.js` 新增**四個槽矩形兩兩不得交疊**的檢查，後續調整版型時如果座標再重疊，會直接報錯。這是本款專屬的版型保護，不改共用接入層。

### v0.4 → v0.5 槽位置與尺寸

| 方向 | A 主槽（v0.5） | B 副槽（v0.5） | 上下主槽間距 |
| --- | --- | --- | --- |
| 直式 | `x=48、181×416` | `x=229、124×376` | 5 SVG 單位 |
| 橫式 | `x=52、230×278` | `x=282、157×262` | 5 SVG 單位 |

尺寸是藝術字**可用槽位**而非字體像素。槽間不交疊是幾何保證；因不同藝術字有各自的可見空白與裝飾，**不能保證所有款式視覺上都像一個完整字串**，但至少不該再因本款槽位重疊而碰撞。

## 三、投票圈選章：照作者提供的參考圖

原先的「黑色圓圈＋數字 1」以及另設於下方的紅印章都作廢。**v0.4 起以紅色圈選章取代左上號次，只留這一枚；v0.6 進一步將它移到右側人物圖片框的左上角，跨過圖片框邊界。**

作者上傳的參考圖，符號形狀是：

1. **一個粗的紅色正圓外框**。
2. **一條水平紅線**橫穿圓形正中央。
3. **一條自圓心附近向右下斜出的紅線**，斜線末端接近圓環右下緣。

**不是打勾、不是雙圈、不是虛線、也不是寫「1」的號次牌。** SVG 以 `circle`、`line` 製作，清楚可縮放。預設只使用這個紅色圈選印記，不引入政黨標誌或黨派配色。

## 四、照片、背景與直橫版

- 僅有一個大型候選人照片框 `billboard-photo`，位於**右側**。
- 整張背景預設 `transparent`，避免以大片預設底色聯想到政治立場；使用者仍可透過原有共用 UI 改背景。
- 看板本體保留中立白底與輕灰色框線；照片開口保留透明洞，避免模板繪圖蓋掉上傳照片。
- 直式、橫式各自保存槽位與圖片比例，不共用其他封面的版型。
- 字槽可延伸到照片框附近；照片仍是視覺主體。

## 五、版本修正原因

- **v0.1：** 初版為橫排主副標、數字號次與額外印章。
- **v0.2：** 改成直排，但錯排成四條並列。
- **v0.3：** 作者更正為左大右小、上下各一；仍留有分隔線、字體過小和錯誤印章。
- **v0.4：** 作者要求放大藝術字槽、左右及上下緊密相連、完全不要分隔線；「1」號次直接換成**參考圖的紅色圈選章**。但當時誤將「緊密」做成槽位互相覆蓋。
- **v0.5：** 作者換成其他藝術字時發現疊字；修正 v0.4 的槽位幾何重疊、保留緊湊直排與原本的視覺裝飾，並增加不重疊檢查。
- **v0.6：** 作者要求紅色圈選章**往右移，約疊在人物圖片框左上角**。直版印章中心由 `(127,144)` 調至 `(365,130)`；橫版由 `(131,134)` 調至 `(458,126)`；半徑分別維持 `76`、`80`。印章改在照片邊框繪製後再蓋上，確保真正跨越邊界；四個藝術字槽不動。

## 六、檔案與獨立性

- `index.html`：本款頁面入口（這次不修改）。
- `billboard_layout.js`：本款兩組四槽、背景預設、圖片框與圈選章座標。
- `billboard_visual.js`：本款獨有的 SVG 看板、邊框、正確圈選章。
- `README.md`：本設計的歷史與作者決策。

共用的是藝術字接入、圖片上傳、預覽與匯出**功能**；本款**絕不引用其他作品專屬的 layout 或 visual**。v0.6 只修改本款的 `billboard_layout.js`、`billboard_visual.js` 與 `README.md`，不改 News、Textbook、Joker、Social，也不改共用層。
