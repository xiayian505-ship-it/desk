# 慢慢封面｜《一錢不值》設計與更新說明（Dollar v0.2：接字防重疊／共用合成器複製）

> 中文主題：**一錢不值**｜英文代號：`dollar`（D）  
> 原型：美國一美元紙鈔**正面**的視覺語言（僅作小說封面藝術化轉譯）。  
> 預設配字：A **一錢不值**、B **嗜財如命**；上下兩排完全相同。  
> 預設藝術字：現有目錄的 `gold`，其**正式名稱是《金碧輝煌》**（不是另外新增的「金幣輝煌」）。

## 設計原則：簡單、像美元，但不是重製美鈔

這是小說封面，不是鈔票掃描、真鈔重繪或防偽圖案練習。作者明確希望**以最少的視覺資訊喚起「美金」印象**，如果幾乎一模一樣反而不是目標；雕花太多也會和本來就有特效的藝術字搶視線。

因此固定視覺只有：米白偏綠的美鈔紙色、墨綠雙／多層外框、四角數字 `1`、少量對稱抽象花飾、中央橢圓肖像邊框。這些固定元素全部是本款 `dollar_visual.js` 的原生 SVG 線條、橢圓與向量數字，**沒有**複製真鈔照片、官方印章、真實序號、國徽或原鈔固定文字；也沒有另外硬塞非必要的文案、簽名或細節。

整張封面的預設背景色是 `#E8E9D7`，邊線墨綠 `#305841`，配上低彩度綠色細紋；不會因為預設藝術字是金色系而把整張封面改為金色系。全封面背景依然遵從現有共用設定，可手動換色、透明、撞色、漸層或選圖。

## 文字：上下兩組 A＋B，共四個獨立槽

| 區域 | A 槽預設 | B 槽預設 | 閱讀結果 |
| --- | --- | --- | --- |
| 上排文字 | 一錢不值 | 嗜財如命 | 「一錢不值嗜財如命」 |
| 下排文字 | 一錢不值 | 嗜財如命 | 「一錢不值嗜財如命」 |

每槽分別保留共用 UI 原有的 **1～4 字輸入、獨立換款與自動適配**，絕不合成一個無法單獨編輯的文字槽。版面上，**A 靠右、B 靠左，兩個 SVG 槽框只輕微重合 12px 以抵銷內部留白**，不再讓兩組藝術字筆畫重疊；預設仍應讀成同一句，不是隔很開的兩個標題。即使兩區預設文字相同，仍是上／下各自獨立的兩組槽位。

使用 `gold` 是因為 ZIP 內的 `word_catalog_data.js` 和 `entries/gold.js` 已經收錄這款藝術字，正式顯示名稱《金碧輝煌》；沒有改動藝術字名稱、生成器或目錄，也不需另外提供 `word.zip`。

## 圖片：中央橢圓肖像（僅一框）

`dollar-portrait` 是本款唯一可上傳的圖片框，沿用原有圖片選取、移除、背景、直橫切換與 SVG/PNG 匯出功能。框位置延續一美元正面的中央華盛頓肖像概念，但上傳的是使用者自己的小說人物圖片。

**圖片與圖片框背景都是真正的 SVG 橢圓**，不以不透明米白色去遮住矩形的四角：這樣使用共用的透明／漸層／整張背景圖片時也不會露出方形照片。為了做到這點，Dollar 使用的共用合成器已支援**可選的** `clipShape: "ellipse"`：指定此值時，圖片、圖片框背景使用橢圓；既有模板沒指定此值仍使用原本的矩形，不改動舊模板設計。

## 直式／橫式各自編排

- **直式：840 × 1200**。四角 `1` 靠近紙張角落，A／B 在上方一整行與下方一整行；中間橢圓圖片框 `(218, 316, 404, 568)`。直式重新設計為直向小說封面，而不是把真美元橫向紙鈔強迫旋轉。
- **橫式：1200 × 840**。上下文字仍各是一行，橢圓圖片框 `(405, 183, 390, 474)`；左右空間容納對稱的抽象線條裝飾。橫式有獨立座標，沒有縮放直式位置了事。
- 兩方向的圖片框 ID 固定為 `dollar-portrait`，切換方向可沿用同一張上傳圖片。
- 繼續使用工作台原本的 SVG、PNG，及**直式**書封 PNG 輸出。

## v0.2 修正：藝術字連續但不重疊；共用合成器先複製到 shared

使用者實際預覽確認：先前 A/B 槽框交疊造成《金碧輝煌》的「值／嗜」等接縫筆畫互相壓住。這不是字型錯誤，而是本款排版設定過度靠近。

- 直式原本 A/B 槽位相互覆蓋 **86px**，橫式覆蓋 **68px**；改為**兩方向都只輕微交疊 12px**（相較舊版大幅減少），大小維持原有設定，A/B 分別採 `xMaxYMid meet`／`xMinYMid meet` 貼向句子的接合處，仍保持視覺上連成一句。
- 上下兩排同步處理，兩個 A/B 文字區仍是四個可獨立修改的藝術字槽。
- 範圍僅限 `dollar_layout.js`；其他模板不受影響，也沒有改動共享的藝術字測量規則。
