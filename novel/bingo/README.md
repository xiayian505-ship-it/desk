# 構思賓果 v1.5｜4×4 極簡版

部署：將 `novel/bingo/` 放入 `desk` 專案。軍火庫透過 HTTPS 絕對網址載入，功能與 UI 分檔，不複製零件原碼。

## 功能

- 4×4 共 16 格、10 條賓果線。六類 36 種題目。
- 固定：每大類前兩項各一格，另外四格為「配角人設」。
- 隨機：前四類同名可重複，後兩類每題至多一次。
- 自訂：跨六類自由選題及指定同名項目次數。
- 多小說、多賓果牌、每個格子獨立 UID；勾選、重新排列、PNG 展示卡。
- 作品名稱可留白：自動取名 `構思賓果 YYYY-MM-DD`（使用本機日期）。可重新命名。
- **賓果牌名稱可留白**：依模式自動取名 `固定賓果 1`／`隨機賓果 1`／`自訂賓果 1` 等。即使後來刪除／重命名其他牌，新建牌仍選用目前不衝突的編號；亦可重新命名，若改名時留白則重新產生預設名稱。
- 程式內正常使用的資料由 `FictionStorage` 本機儲存，命名空間 `sbs_story_bingo`。

## 改版原則

**不為舊資料保留或版本相容增加處理。** 改版時舊資料可清空；不保證舊版存檔能被新版讀取。這不影響目前版本建立資料後的正常儲存功能。

## 檔案

- `index.html`：主畫面及 HTTPS 軍火庫引用
- `bingo.js`：題庫、UID、抽題、判定、本機存取、展示卡
- `bingo.css`：功能基本樣式
- `bingo_style.js`：UI 行為
- `bingo_style.css`：視覺排版
- `SPEC_v0.8.md`：規格與軍火庫對照
