# 構思賓果 v2.7｜4×4 極簡版

部署：將 `novel/bingo/` 放入 `desk` 專案。軍火庫透過 HTTPS 絕對網址載入，功能與 UI 分檔，不複製零件原碼。

## 功能

- 4×4 共 16 格、10 條賓果線。一般模式六類 36 種題目，特殊模式另有 16 個專用題目。
- 固定：每大類前兩項各一格，另外四格為「配角人設」。
- 隨機：前四類同名可重複，後兩類每題至多一次。
- 自訂：跨六類自由選題及指定同名項目次數。
- 多小說、多賓果、每個格子獨立 UID；勾選、重新排列、PNG 展示卡。
- `record/` 是獨立構思紀錄頁：16 個題目以互斥開合編輯、切換小說與賓果；草稿自動暫存、取消可還原、確認後才寫入正式內容；同名格子不共用內容。
- 作品名稱可留白：自動取名 `構思賓果 YYYY-MM-DD`（使用本機日期）。可重新命名。
- **賓果名稱可留白**：依模式自動取名 `固定賓果 1`／`隨機賓果 1`／`自訂賓果 1` 等。即使後來刪除／重命名其他賓果，新建賓果仍選用目前不衝突的編號；亦可重新命名，若改名時留白則重新產生預設名稱。
- 程式內正常使用的資料由 `FictionStorage` 本機儲存，命名空間 `sbs_story_bingo`。

## 改版原則

**v2.7 保留目前已部署版本的資料。** 本次不提升 `schemaVersion`，因此已保存的小說、賓果、格子完成狀態、流光設定及構思草稿都會沿用。不額外撰寫更早期測試版的資料遷移邏輯。

## v1.9 純文字操作與線條特效

- 主頁、彈出視窗與構思紀錄頁的操作按鈕統一為純文字（賓果格本身不改）。
- 紀錄頁 16 個題目按鈕不再使用獨立圓角卡片外觀，保留獨立格子 UID 和完成／編輯狀態。
- 以 HTTPS 絕對網址載入軍火庫 Minimal Underline：`https://lib.stillnessbyslowly.com/effects/line/underline.css`。
- 宿主僅透過 `--slowly-line-size: 70%`、`--slowly-line-origin: center` 和定位控制外觀；不複製軍火庫的動畫原始碼。
- 尚未部署；此版無資料遷移。


## v2.0｜編輯與選單

- 主頁／record/ 的小說與賓果使用軍火庫 `SlowlySelect`，宿主設定色彩。
- record/ 使用軍火庫 `SlowlyAccordion` 互斥開合，每次只編輯一格。
- `record_drafts` collection 暫存尚未確認的文字，確定按「確認」才寫回 `cells.content`；按「取消」刪除草稿並恢復已確認內容。
- 草稿和正式內容均使用同一個 FictionStorage namespace `sbs_story_bingo`；不改格子 UID、賓果內容或 PNG。


### v2.1 視覺調整

- 保留 4×4 賓果本身的外框與格子設計。
- 移除主頁其他操作區、空白狀態的卡片外框。
- 移除紀錄頁選擇區、題目清單與編輯區的卡片外框，改以文字及分隔線呈現。
- 不調整原本 JS、UID、軍火庫引用與草稿取消／確認流程。


### v2.2｜構思紀錄 2×8

- `record/` 的 16 個構思題目改為兩欄、每欄八格，包含手機版。
- 點開任一題後，編輯器橫跨兩欄以保留書寫寬度。其餘題目仍維持兩欄。
- 保留 `SlowlyAccordion` 互斥開合、原本草稿暫存和取消／確認；未更動資料結構或 JavaScript。


### v2.3 完成格流光切換

- 完成格外觀可選 **一般** 或 **流光**，預設一般；選擇會使用 `FictionStorage` 的 `sbs_story_bingo:settings` 保存，重開仍採用上次選擇。
- 流光是已完成格持續流動邊框與光暈；取消勾選立即停止。切回一般模式只改外觀，保留每格完成狀態與 UID。
- 直接引用 `https://lib.stillnessbyslowly.com/effects/light/electric_border.css`；沿用軍火庫 `slowly-electric-border with-glow is-active`，以子層避開既有賓果格偽元素衝突。不複製軍火庫零件。
- `prefers-reduced-motion` 時依軍火庫規則停止持續動畫。
- 流光是網頁互動外觀，PNG 展示卡沿用原有的靜態完成格呈現。


### v2.4 流光外框與 SVG 標題

- 流光模式保留軍火庫 Electric Border 原生 `::before` 邊框動畫；`with-glow::after` 僅以宿主 CSS 補上中空遮罩，避免彩光充滿格子中央。一般模式完全不變。
- 主頁藝術字改載入現成的 `./bingo_icon.svg`，不再把社群預覽 PNG 當作畫面標題；`og:image` 仍使用既有 PNG。
- 格子完成值、模式切換、UID、資料儲存與構思紀錄頁全部不變。本版不考慮舊資料相容。


### v2.5 視覺調整

- 流光模式下，已完成格不再套用一般完成態的深色底與勾選色塊，只保留外框電光。


### v2.6｜SVG 標題尺寸

- SVG 原檔未變更，主頁依 2.5:1 的呈現框裁切上下畫布留白，採響應式置中顯示；不再沿用 PNG 的負邊距。


### v2.7｜特殊賓果與命名一致性

- 新增第四種模式「特殊賓果」，只使用 16 個固定的個人題目，一次各取一題並隨機排列。
- 一般固定、隨機、自訂模式仍僅使用原本 36 題；不將特殊題目混入一般選擇器。
- 特殊賓果的 `mode` 為 `special`，預設名稱依序為 `特殊賓果 1`、`特殊賓果 2` 等，重新排列仍保留格子 UID 與完成及構思內容。
- 特殊題目使用 `special.*` topic_id。主頁、構思紀錄與 PNG 均能顯示正確名稱。
- 主頁、構思紀錄、彈出視窗與提示文字的稱呼統一採用「賓果」；資料鍵、UID、localStorage namespace 不動。
- 部署後沿用 `schemaVersion = 2`，不清理任何已存在的作品與暫存資料。


### v2.8｜構思點擊模式與自訂混搭

- 主頁切換「一般／流光／構思」：一般與流光可勾選，構思則點格子跳到 `record/?novel_uid=...&board_uid=...&cell_uid=...`。
- 切換「構思」時沿用上次選的完成格外觀（一般／流光），不改既有完成狀態、進度、特殊題目或 UID。
- record/ 透過 `cell_uid` 自動展開對應構思；草稿與確認／取消流程不變。
- 自訂賓果可從一般 36 項＋特殊 16 項合計 52 項中選擇、重複指定次數；固定／隨機與特殊賓果的原有生成規則不變。
- 主頁選擇器移除「完成格」前綴；使用者介面文案「題目」改為「構思」。
- `settings` 中保留原 `completionStyle`，新增可選 `cellClickMode`，不更改 `schemaVersion = 2`，沿用現有本機資料。
