# 第 46 款｜死於非命（Ill Fate Lettering）

> **原始構思保留**：本文件包含依照先前生成的「幽冥咒印」參考圖討論、確定的整套視覺設計，而不是只記錄檔案名稱。此款遵守 `word/word_readme.md` 的全系列固定規則；**作品頁沿用 `word/shared/word_page.js`，生成器由軍火庫 HTTPS 直接載入**。

## 一、作品設計構思（保留原定案）

**名字：** 死於非命

**主題意象：** 幽冥、咒印、意外非自然死亡、陰氣纏身；風格是被詛咒的題字或靈異傳說的封印標記，陰森、詭異、帶儀式感。不是搞笑萬聖節、不是寫實血腥，而是邪異、冷冽、有壓迫感。四個字本身是主體，不把字貼在背景海報上。

**配色：** 黑、炭灰、骨白、冷白為主，少量冰藍／幽青冷光。主字由灰白至骨白的破損石刻／金屬質地構成，筆畫緣有深色暗影，細裂處用冷色微光。**不使用鮮紅或大片深色底板。** 配色由作品固定，不開放調色。

**字與字之間：** 直式主範例由上到下排列「死／於／非／命」，不是機械等距格線；四字的傾斜角度與重心略有不同，像垂直墜落的咒印。橫式獨立安排橫向字距、封印碎弧、懸符位置，不將直式旋轉。1～4 字皆應重新計算字距、大小與中央留白，不只支援四字範例。

**主題線條：** 字的筆畫具有破裂、斷痕、風化、剝落的質感；以骨白裂字、冷灰雙層陰影、細碎亮痕讓字體自己撐住畫面。中後景使用殘缺月輪、封印圈、陰氣煙絲與柔細的環繞軌跡；部分線條略微越過字緣，但不能讓文字不可讀。字內裂紋使用裁切，讓光痕只出現在真正筆畫內。特別避免科技掃描 UI 與整塊盾牌構圖。

**元素點綴：** 小型破損符紙、帶墨跡的咒條、細繩、懸垂銅錢／小型符印、風化碎片、冷白星點、斷裂封印圈。元素分布在字旁及文字前後，具明確相對位置；數量節制，不能遮住文字主體。原生成圖那種幽冥氣場由**分散的細煙線條、殘符、懸飾**表達，不用密實黑煙襯底。

**軍火庫特效（核對及實作方式）：**
- **文字生成器**：使用慢慢軍火庫正式 HTTPS 的 `SlowlyTextGenerator`、`SlowlyHorizontalTextGenerator` 與 `SlowlyTextGeneratorCore`；共用機制負責 1～4 字輸入、SVG／PNG／書封匯出。本款 JS 僅繪製自己的 SVG。
- **Shine Text／Gold Rain／Minimal Underline**：構思時曾討論用其冷光掃過字面、灰藍陰塵與殘缺細線的視覺概念；但這些網頁 CSS／粒子效果不直接等同於可自足的 SVG 匯出。本款沒有虛構其 API 或複製軍火庫程式碼，而是把相應視覺**以專屬 SVG 的漸層、裂痕、細粒、封印弧線與 SMIL 動畫實作**。網站不另接不必要的 DOM 特效。

**特殊要求：**
1. **絕對禁止大型底板和背景色塊**：不在字後放任何成片的黑／灰色襯底、圓形底盤、盾牌、橢圓底墊，或把厚重整團煙霧充作變相底板。
2. 背景完全透明；細煙可以存在，但線條必須零散、輕薄、保留留白，**不能在四字後連成密實色塊**。
3. 骨白風化裂字、幽藍冷光、破符、懸飾、殘月輪與詭異氣氛；不得變成血字、可愛鬼怪或萬聖節貼紙。
4. 靜態 SVG、透明 2× PNG、700 × 1000 書封 PNG 和自足動態 SVG，均應包含全部指定視覺元素。棋盤格只在網站預覽舞台中，不能匯出。
5. 動態 SVG：陰氣煙線慢慢飄動，符條輕晃，封印冷光沿碎環移動，星點微閃，裂字有少量幽青掃光；不要讓字體亂跳或做誇張恐怖效果。

## 二、實際繪製與排版

- `ill_fate_template.js` 自行生成文字的多層風化骨白 SVG、破裂裁切、斷環、細陰氣、符紙、懸飾及動畫，**不是引用上一款 SVG 模板換色**。
- 背景沒有任何整幅 `<rect>`，也沒有大面積不透明煙霧 `<path>`；裝飾是線、碎片、零散小物件。
- 直式 `840 × 1200`、橫式 `1200 × 760`；透明 PNG 各兩倍、書封 `700 × 1000`、動態 SVG 直橫式。
- 特效位置跟隨方向調整；主字依實際輸入拆為 1～4 字元。

## 三、接入架構

- `index.html`：沿用慢慢藝術字共用 UI，附 `word-preview-template`；HTTPS 載入軍火庫原件。
- `ill_fate_template.js`：本款全部可匯出 SVG／視覺及動態邏輯。
- `ill_fate.js`：直式 SVG、透明 PNG、書封；使用軍火庫原件。
- `ill_fate_horizontal.js`：橫式獨立下載生成器。
- `ill_fate_animated.js`：直橫式自足動態 SVG 生成及下載。
- `ill_fate_style.js`：僅作品標題、範例、生成器名稱的設定。
- `ill_fate.css`：僅本款透明棋盤格預覽舞台，不更動全站樣式。
- `word/index_data.js`：主頁新增第 46 款的卡片索引；其餘項目不改。

## 四、交付與部署

解壓 ZIP 到 `desk/` 根目錄，保留 `word/ill_fate/` 的路徑；`word/index_data.js` 只增加一筆最新作品資料。手動刪除路徑：**0 個**。
