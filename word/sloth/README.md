# 好逸惡勞｜Sloth Lettering・獨立重製版

## 作品想法

懶惰不是一塊軟墊，而是**連字都不肯好好站著**。

這次把原本「大床墊＋整齊文字」的構圖完整取消，主角變成四個棉絨般鬆塌的字：字幅壓寬、字身壓低，有的往左傾，有的向右滑，四字依序錯位。文字才是軟爛的主體，而不是坐在一張大背景板前面。

- **色系**：灰藍棉絨、奶白柔光、淡薰紫布邊；低彩度、沒有強烈霓虹或金屬質地。
- **字體材質**：棉絨般的柔軟厚度、褶皺與不規則下垂線，直接寫在各字的 SVG 圖層內。
- **小枕頭**：只在局部字角，像剛好讓某個字偷懶靠一下；不再畫出承載全幅作品的大床墊。
- **垂布**：沿部分字的側邊鬆鬆滑落，不做環形背景、框線或底板。
- **點綴**：稀少睏倦弧線、柔白小雲線、慢慢往下沉的淡色星點；不密集環繞文字。
- **動態**：字極緩慢地往下懶散挪動，布邊輕微呼吸，星點慢慢落下。動畫不依靠網頁 CSS，下載後仍可播放。

《好逸惡勞》不借用其他七宗罪作品的 SVG 模板或繪圖核心，不把七宗罪視為同款設計的換色變體。

## 檔案責任

位置：`desk/word/sloth/`。

- `index.html`：僅提供作品頁要載入的程式和專用預覽舞台；標題、輸入、四個下載按鈕由 `word/shared/word_page.js` 建立。
- `sloth.css`：只處理本款棋盤格與預覽大小，不改共用頁面的配色。
- `sloth_style.js`：本款文字範例及生成器接線。
- `sloth_template.js`：**獨立的 SVG 主字、棉絨褶皺、局部枕頭／垂布、星點與動畫**，本次重製的核心檔案。
- `sloth.js`：直式 SVG／PNG／書封及動態預覽。
- `sloth_horizontal.js`：橫式 SVG／PNG／書封及動態預覽。
- `sloth_animated.js`：直橫式自足動態 SVG 下載。

共用功能只透過 `https://lib.stillnessbyslowly.com/` 直接引用，不複製軍火庫元件。

## 尺寸、透明與部署

- SVG：直式 840 × 1200、橫式 1200 × 760。
- 透明 PNG：直式 1680 × 2400、橫式 2400 × 1520。
- 書封 PNG：700 × 1000、透明。
- 動態 SVG：直式／橫式皆提供，與靜態版相同的字與裝飾。
- 1～4 個字都有自己的排版；橫式不是把直式旋轉。
- 棋盤格只屬於網頁預覽，**所有作品元素都在 SVG 內；輸出保持透明**。
