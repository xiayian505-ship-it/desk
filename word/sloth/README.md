# 好逸惡勞｜Sloth Lettering

## 本款核心

- **概念**：鬆垮軟墊。七宗罪只是構思的來源，本款是獨立藝術字，不需要任何同系列視覺元素。
- **首頁短文案**：灰藍棉絨把字形托成鬆軟弧度，奶白枕角與薰紫垂布慢慢下墜。連飄過的星點，都懶得快一點落下。
- **色系**：主色 #b8c5e0，輔色 #f3e9d6，深色 #6f648b。
- **禁止套版**：`sloth_template.js` 具有本款專屬 SVG 形狀、材質、排列與動畫；**不引用其餘六款作品的 SVG／JS**，不共用任何七宗罪材質生成檔。
- **版型**：支援 1～4 字元，直式 840 × 1200，橫式 1200 × 760；並為橫式獨立佈局。

## 生成、下載與預覽

- `index.html`：本款最小預覽舞台，載入 `../word_style.css` 和 `../shared/word_page.js`。
- `sloth.css`：只管本款預覽棋盤格及尺寸，不能替換全站統一 UI。
- `sloth_style.js`：共用 UI 的本款設定。
- `sloth_template.js`：本款**完全獨立的完整 SVG 繪圖核心**（不是共用的七罪 template）。
- `sloth.js`：直式產生器。
- `sloth_horizontal.js`：橫式產生器。
- `sloth_animated.js`：本款可獨立開啟的直橫動態 SVG 產生器。

全部 SVG 元素跟著 SVG/PNG/書封/動態 SVG 下載；只有網站棋盤格用於檢視，不在輸出內。

所有軍火庫元件都經 `https://lib.stillnessbyslowly.com/` 直接引用，不打包副本。

下載四種模式不加新按鈕：SVG、透明 PNG（2×）、700×1000 書封 PNG、動態 SVG。
