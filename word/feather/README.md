# 黑羽舞動｜慢慢藝術字

- 位置：`desk/word/feather/index.html`
- 目錄：`word/index_data.js` + `word/index_style.css` 新增 Feather
- 輸入：1–4 字，直式、橫式；4 字設計預設「黑羽舞動」
- 色系：黑、灰、銀、白及低彩度冷光，字體不是整片純黑
- 文字：斷裂相位交錯的兩重外框、SVG 漸層光澤（SVG 對應 Shine Text）
- 構圖：單一斜向雙箭頭從首字上方貫穿到末字下方，壓在字面；分散實心羽毛，下方 2/3 為主
- 粒子：網頁引用軍火庫 Gold Rain；靜態 SVG 粒子獨立存在，動態 SVG 另有原生下落動畫
- Minimal Underline：網頁引入原件 70% 線長；輸出以錯位虛線斷框對應，不引用外部 CSS

## 輸出

- 靜態 SVG：840×1200 / 1200×760，透明背景
- PNG 2x：1680×2400 / 2400×1520，透明背景
- 角角者書封 PNG：700×1000，透明背景
- 動態 SVG：自足動態，文字、羽毛、雙箭頭、粒子與炫彩仍在一個檔案

## 軍火庫

只以 HTTPS 絕對網址引用共用文字生成器與三個原件，不複製軍火庫原始碼。
SVG 是宿主文字設計的獨立輸出，不會將網頁背景寫入 PNG。

## 發佈

將壓縮包內的 `word/feather/`、`word/index_data.js`、`word/index_style.css` 放到 desk 對應路徑即可；原有系列無須修改。
