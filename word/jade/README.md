# 玉潤生輝｜慢慢藝術字（jade v2）

- 主題：玉鐲、天然玉石、柔和礦脈與局部打亮；以淺玉綠、青綠、翠綠為主，透明外框（無不透明字體描邊）。
- 路徑：`word/jade/index.html`
- 字數：1～4 字，可使用中文或英文；會依字數調整直式、橫式構圖。
- 直式 SVG：840 × 1200；透明 PNG：1680 × 2400。
- 橫式 SVG：1200 × 760；透明 PNG：2400 × 1520。
- 書封：700 × 1000 透明 PNG。
- 動態：本次未指定動畫，第四個按鈕保留但停用。
- 共用頁：保留 `word/shared/word_page.js`、`word/word_style.css` 及既有 HTTPS 軍火庫元件。
- 專屬繪圖：`jade_template.js` 完整實作 SVG 玉石字形、細密礦脈、玉鐲圓環、斜向波形雙字弧線與銜接筆畫，**不依賴** `word_material_core.js`。

## 精修後構圖

- **直式**：四字交錯排列；相鄰兩字以專屬玉質連筆銜接，前一字的下緣延伸至下一字的上緣；兩字一組配一條不規則斜向半圓波弧。
- **橫式**：四字上下錯位；首字下緣延伸出一條長玉質筆畫，從其他字下方掠過，延至末字下方；兩字一組配一條波弧。
- **點綴**：空心玉鐲綠 SVG 圓環置於主字周圍留白，環內透明；不要將圓環做成字後方的大片背景。
- **玉質**：字形內有多層翠綠漸層、輕微乳白雲絮、礦脈細線及局部玻璃感反光。紋理經各字形裁切，非矩形貼片。
- **輸出**：所有主字、長筆、連筆、弧線、玉環及玉石紋理皆包含在自足 SVG 內；PNG 與書封依原有下載機制轉出。沒有網頁棋盤格或 UI 背景。

文字生成功能仍沿用正式 HTTPS 軍火庫原件（引用、不複製），但作品的**圖像主體由本款專屬模板繪製**。日後修改此款不應回退到共用材質核心。
