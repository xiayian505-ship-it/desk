# 陰陽相生｜慢慢藝術字（yin-yang v2）

- 材質方向：黑白互生、鏡像構圖、太極旋流與陰陽雙點
- 路徑：`word/yin-yang/index.html`
- 字數：1～4 字；直式 840×1200 SVG / 1680×2400 透明 PNG
- 橫式：1200×760 SVG / 2400×1520 透明 PNG
- 書封：700×1000 透明 PNG
- 動態：提供可下載的動態 SVG（SMIL）；普通 SVG/PNG 保持靜態。
- 軍火庫：文字產生器、Canvas PNG、Blob URL 以 HTTPS 絕對網址引用。
- 本款已改為獨立核心：`yin-yang_core.js` 負責鏡像字位、黑白流場、太極旋流、雙點與動態，不再依賴 `word_material_core.js`。
- 無外部圖片或字型檔；透明背景，所有黑白流場、流線與圖騰皆由 SVG 程式生成。

## 說明

本次精修保留原版的黑白太極主題，但把重點從「字內裝飾」提升為「文字本身的陰陽構圖」。
四字時採用「正常 → 左右鏡像 → 上下鏡像 → 正常」的字位節奏，並以黑白雙流線在字外互繞，字內則讓暗面與亮面彼此滲透，形成「陰中有陽，陽中有陰」的畫面。
動態 SVG 只讓光影、流線與雙點緩慢循環，不讓整體文字翻轉，保留閱讀穩定性。
