# 流沙歲月｜慢慢藝術字（quicksand v2）

- 材質方向：流砂、沙灘、金砂、滿溢而出的沙色填面
- 路徑：`word/quicksand/index.html`
- 字數：1～4 字；直式 840×1200 SVG / 1680×2400 透明 PNG
- 橫式：1200×760 SVG / 2400×1520 透明 PNG
- 書封：700×1000 透明 PNG
- 動態：保留可下載的動態 SVG（SMIL）；普通 SVG / PNG 保持靜態
- 軍火庫：文字產生器、Canvas PNG、Blob URL 以 HTTPS 絕對網址引用，預覽搭配 glow + lift CSS 原函式
- 藝術字本體：改為 `quicksand_core.js` 獨立繪圖，不再依賴 `word_material_core.js`
- 無外部圖片或字型檔；流沙、沙粒、短橫線、局部打亮皆直接繪入 SVG
- 版權／字型授權說明在藝術字主頁統一管理

## 本次精修重點

1. 建立 `quicksand_core.js`，獨立處理直式、橫式與動態 SVG 輸出。
2. 主字外框清楚保留，內部填色改為超出字體框線的流沙感。
3. 直式以左側流沙連接下一字；橫式以右側流沙連接下一字。
4. 未連接的一側加入淺金色短橫線點綴。
5. 每字內部維持大量沙粒，並改成依重力聚集的分布方式，保留外散沙粒與局部亮光。
