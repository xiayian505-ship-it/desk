# 金碧輝煌｜Gold Lettering v3

**立體燙金浮雕 × 文字內金砂 × 文字外輕陰影**，透明底輸出。

- **1～4 個字、直式與橫式**，沿用慢慢藝術字共用 UI。
- **SVG、透明 PNG（直式 1680 × 2400；橫式 2400 × 1520）與 700 × 1000 角角者書封 PNG**。
- 無金塊、金幣、寶石，也沒有背景光暈或額外外框裝飾。
- 多層字形切面、燙金反光及微陰影，全部保留在下載的 SVG / PNG 本體。
- 金砂由 `gold_visual.js` 程式化生成，必須由文字遮罩裁切；橫式、直式共用相同視覺實作。
- 網站預覽額外引用軍火庫 `effects/light/glow.css`，滑鼠懸停時有極淡金色柔光，宿主 CSS 控制亮度；此效果**僅為預覽互動**，非下載裝飾。
- 共用文字產生、Blob URL、Canvas PNG、下載皆直接引用 `https://lib.stillnessbyslowly.com/`，不複製軍火庫。

檔案：`index.html`、`gold_template.js`、`gold_visual.js`、`gold.js`、`gold_horizontal.js`、`gold.css`、`gold_style.css`、`gold_style.js`。
