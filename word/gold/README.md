# 金碧輝煌｜慢慢藝術字

- 英文代號：`gold`
- 預設代表文字：`金碧輝煌`
- 形式：直式＋橫式
- 下載：SVG、透明 PNG、角角者書封 PNG
- 入口網址：`https://desk.stillnessbyslowly.com/word/gold/index.html`

## 設計方向

燙金、浮雕與珠光。讓文字像站在盛大的光裡。

## 檔案說明

- `gold.js`：直式藝術字生成
- `gold_horizontal.js`：橫式藝術字生成
- `gold_template.js`：直式 SVG 模板
- `gold.css`：預覽區與主題畫面樣式
- `gold_style.css`：頁面主題補充樣式
- `gold_style.js`：輸入、切換與下載互動
- `index.html`：網站入口
