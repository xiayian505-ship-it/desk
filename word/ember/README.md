# 星火燎原｜慢慢藝術字（ember v2）

- 材質方向：焦炭石墨筆畫、赤焰火舌、飛散火星與以「火」字為主的裝飾點綴
- 路徑：`word/ember/index.html`
- 字數：1～4 字；直式 840×1200 SVG / 1680×2400 透明 PNG
- 橫式：1200×760 SVG / 2400×1520 透明 PNG
- 書封：700×1000 透明 PNG
- 動態：提供可下載的動態 SVG（SMIL）；普通 SVG/PNG 保持靜態。
- 軍火庫：文字產生器、Canvas PNG、Blob URL 以 HTTPS 絕對網址引用。
- 本款已改為獨立核心：`ember_core.js` 負責燃燒字面、火舌、火星、拖尾與「火」字點綴，不再依賴 `word_material_core.js`。
- 無外部圖片或字型檔；透明背景，所有火焰、火星與裝飾皆由 SVG 程式生成。

## 說明

本次精修保留《星火燎原》的赤焰主題，但讓文字本身更接近從焦炭到火焰的漸進燃燒。
主字仍是完整四字（支援 1～4 字），外圍另外加入多個小型「火」字作為蔓延中的火種點綴，並對這些裝飾字做不同角度、翻轉方向、大小與透明度變化，讓畫面更像火勢延燒而不是單純畫火焰。
動態 SVG 只讓火焰、火星與裝飾「火」字做輕微明滅與上升，不翻動主字，保留閱讀穩定性。
