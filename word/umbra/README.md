- 字數：1～4 字；直式 840×1200 SVG / 1680×2400 透明 PNG
- 橫式：1200×760 SVG / 2400×1520 透明 PNG
- 書封：700×1000 透明 PNG

- 軍火庫：文字產生器、Canvas PNG、Blob URL 以 HTTPS 絕對網址引用，預覽搭配 glow + lift CSS 原函式

## 本次精修重點

1. 建立 `umbra_core.js`，獨立處理直式與橫式輸出。
2. 文字構圖改為交錯飛躍，一前一後、一上一下的錯位節奏。
3. 主字加入左上至右下的偏光漸層，並保留黑白雙生重影。
4. 字體外框使用雙線描繪，強化輪廓與層次。
5. 在四字主題底部鋪入大量高透明度實心圓形，互相交疊並搶佔視覺。
