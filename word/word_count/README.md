# 第 45 款｜字數統計（Word Count Lettering）

## 作品設計

- **名字**：字數統計。
- **主題意象**：即時字元解析引擎。每個輸入字元如同正在讀取的資料單位，不是單純將文字放在深色科技面板上。
- **配色**：科技翡翠青綠、湖水綠、冰薄荷光、銀白刻度；深墨綠只用於主字描邊與陰影。配色固定，不額外加入使用者調色介面。
- **字與字之間**：直式按資料流從上往下排，左側各字有獨立計數軸，右側有 Unicode 識別；橫式以由左至右的序列排列，字元編號在上，字元識別在下。1～4 字元皆有各自的間距與尺寸。
- **主題線條**：每個字有深綠精密外框、青綠金屬光澤，字形內以遮罩承載掃描線、點陣像素、分層的資料細紋。每個字周圍各有四組「非完整矩形」定位角，透明底面保留呼吸空間。
- **元素點綴**：進度刻度、單字節點、`U+` 字元識別、頂部資料進度條、底部數字計數器。全數屬於 SVG 作品本體；沒有整片背景底板。
- **軍火庫特效**：正式 HTTPS 引用文字生成器、透明 PNG 與 Blob 下載功能；專屬的掃描光與青綠筆畫光澤在 SVG 內獨立實作，確保匯出自足，沒有複製軍火庫零件原始碼。
- **動畫**：每個字內的光掃描按字元次序輪流進行；節點與狀態光同步閃爍；底部計數器由 `000` 跳轉到當前輸入字數。靜態 SVG 直接顯示完成後數字，動畫檔內沒有任何外部依賴。

## 功能與輸出

| 類型 | 規格 |
| --- | --- |
| 字數 | 1～4 字元，依文字生成器規則處理 |
| 靜態 SVG | 直式 840 × 1200，橫式 1200 × 760 |
| 透明 PNG | 直式 1680 × 2400，橫式 2400 × 1520 |
| 書封 PNG | 700 × 1000，透明底並完整容納作品 |
| 動態 SVG | 自足的直橫式動畫 SVG |

- 網站共用 UI：`../shared/word_page.js`；共用樣式：`../word_style.css`。
- 直式、橫式、動態輸出皆交由軍火庫正式 HTTPS 原件。
- 透明棋盤格只在網站預覽 CSS 中使用，SVG、PNG、書封均不包含棋盤格。
- 頁面僅需要本資料夾的八個檔案；新增首頁 `word/index_data.js` 一筆目錄，不改全站其他作品。
