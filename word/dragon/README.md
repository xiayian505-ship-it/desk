# 龍騰九霄｜慢慢藝術字（dragon v2）

- 路徑：`word/dragon/index.html`；目錄代號 `dragon` 不變。
- 本款由 **獨立 SVG 模板** `dragon_template.js` 繪製，不再引用 `word_material_core.js`，其他款維持原樣。
- 直式：`840 × 1200` 透明 SVG、`1680 × 2400` 透明 PNG。
- 橫式：`1200 × 760` 透明 SVG、`2400 × 1520` 透明 PNG。
- 書封：`700 × 1000` 透明 PNG；全圖完整置入。
- 動態 SVG：**尚未製作**，共用頁第四個下載按鈕維持停用；不以預覽 Glow/Lift 充當動畫。

## 本款設計

1. **古銅雕塑材質**：古銅金邊、銅像般石灰色主字、墨綠背光陰影，多層描邊與錯位陰影呈現浮凸。以 SVG 漸層和字內偏光繪製金屬光澤，不引用圖片。
2. **龍鱗字面**：半月形龍鱗紋樣以 `pattern` 繪於字形裁切範圍內，不浮到字外；不同角度的細光片覆蓋局部填色。
3. **兩條字間連結**：四字與三字連接第一與第三字，兩字連接第一與第二字，一字保留裝飾弧線。橫式一上一下，直式一左一右；直、橫各自構圖，不直接轉向整幅 SVG。
4. **首字字尾飛躍**：第一字向下一字延伸上揚曲線；不限輸入文字是否真的包含「龍」。一字時以短飛躍弧線收束。
5. **九條龍鬚**：固定九條曲線，分配在現有字位周遭；不同長短、方向、透明度。六條後景、三條前景，避免蓋住主字。龍鬚與連結線都是作品本體的一部分。
6. 依文字 **1～4 字** 分別定義直橫排版位置，保留主字辨識度，透明背景沒有附加預覽框或網站裝飾。

## 檔案及共用功能

- `dragon_template.js`：材質、龍鱗、雙線、飛躍筆勢、九條龍鬚，輸出自足的 SVG。
- `dragon.js`：直式 1～4 字構圖及 SVG、透明 PNG、書封 PNG 生成器接線。
- `dragon_horizontal.js`：橫式 1～4 字獨立構圖與相同下載能力。
- `dragon_style.js`：只設定作品名稱、範例、直橫式生成器。
- `dragon.css`、`dragon_style.css`：預覽與本款色票；不決定輸出的 SVG 內容。
- `index.html`：沿用 `../shared/word_page.js`、既有軍火庫文字／PNG／Blob URL 元件與 Glow/Lift 特效的 HTTPS 原件，不複製軍火庫功能。
