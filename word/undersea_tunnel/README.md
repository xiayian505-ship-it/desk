# 第 37 款｜海底隧道（Undersea Tunnel Lettering）

## 設計核心

- **關鍵意象**：人造的深海耐壓玻璃隧道。文字如同安置在艙壁中的冷光金屬銘牌，延伸的結構環把視線引向深處艙門。
- **固定色系**：藍黑深淵、深海藍、鈦青金屬、冷青導引光，少量暖金色安全信號燈。配色不交由使用者調整。
- **字體**：冷色鈦金屬亮面，雙層金屬描邊、深藍投影與外輪廓；鉚釘與定位刻度沿字邊分布。
- **字間與主題線條**：字與字間保留呼吸間距。細長冷光燈帶沿隧道延伸，透視環、固定鋼件及深處出口包圍文字；不是單純裝飾文字背景。
- **小裝飾**：耐壓固定鉚釘、接縫、深度尺刻度、遠處出口的方向指引以及極少量艙外生物光點。
- **直式**：遠處艙門在頂端；橢圓結構環隨視線從上往下擴大，表現直向深潛。
- **橫式**：遠處艙門在右端；沿水平方向收束的隧道環與導引燈帶，重新設計透視而不是旋轉直式畫面。
- **動態**：燈帶沿道路前進，壓力固定件依序呼吸，出口燈與艙外光點輕微閃爍，字內掃描亮帶緩慢掠過。沒有海浪、霧氣或漂浮泡沫動畫。

## 與《煙波浩渺》區隔

《煙波浩渺》主題是海面波紋、浪尖、雲影與字內霧色；《海底隧道》改用耐壓艙、幾何透視、金屬結構與冷光導航。主體是人工隧道建築，不是另一款水紋字或海面場景。

## 結構與檔案

- `index.html`：共用 UI 所需腳本及預覽 `<template>`。
- `undersea_tunnel.css`：本款預覽舞台棋盤格與圖片顯示，不控制全站 UI。
- `undersea_tunnel.js`：直式 SVG、透明 PNG、書封 PNG 生成器及動態預覽。
- `undersea_tunnel_horizontal.js`：獨立橫式生成器及動態預覽。
- `undersea_tunnel_template.js`：本款專屬 SVG 幾何與美術內容。
- `undersea_tunnel_animated.js`：自足式直／橫動態 SVG 匯出。
- `undersea_tunnel_style.js`：共用作品頁的設定資料。

共用作品頁使用 `../shared/word_page.js` 和 `../word_style.css`。下載端引用慢慢軍火庫正式 HTTPS 文字生成器，沒有複製庫程式或另建 `lib/`。

## 輸入與下載

- 輸入 1～4 字元，可使用既有文字生成器支援的中文、英文及 Unicode 字素；1、2、3、4 字均有獨立字距配置。
- 直式 SVG：840 × 1200；透明 PNG：1680 × 2400。
- 橫式 SVG：1200 × 760；透明 PNG：2400 × 1520。
- 書封 PNG：700 × 1000，內容完整置於透明畫布。
- 直、橫動態 SVG：各自獨立動畫，包含字體、金屬描邊、透視艙壁、燈帶、鉚釘和所有裝飾。
- 背景透明：深藍填色僅存在作品隧道艙體內，不是整張不透明底色；棋盤格僅供網站辨識透明區域。
- 作品的 SVG 不連接外部圖片、字型檔、JavaScript 或 CSS。字型使用裝置可用的字族清單，缺字時依瀏覽器字型回退。

## 主頁與部署

首頁 `word/index_data.js` 新增作品資料，依代號 `undersea_tunnel` 自動歸類 U 分頁；縮圖使用全系列共用的極簡封面，不變動全站卡片設計。

ZIP 的所有檔案均以 `desk/` 為解壓根目錄；僅新增本款資料夾與更新 `word/index_data.js`。
