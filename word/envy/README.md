# 妒火中燒｜Envy Lettering

## 本款核心

- **概念**：毒藤裂鏡。七宗罪只是構思的來源，本款是獨立藝術字，不需要任何同系列視覺元素。
- **首頁短文案**：毒綠暗焰舔過斷裂鏡片，帶刺藤蔓沿扭曲筆畫悄然攀附。倒映裡那雙眼睛，始終盯著不屬於自己的光。
- **色系**：主色 #a0eb51，輔色 #963768，深色 #271333。
- **禁止套版**：`envy_template.js` 具有本款專屬 SVG 形狀、材質、排列與動畫；**不引用其餘六款作品的 SVG／JS**，不共用任何七宗罪材質生成檔。
- **版型**：支援 1～4 字元，直式 840 × 1200，橫式 1200 × 760；並為橫式獨立佈局。

## 生成、下載與預覽

- `index.html`：本款最小預覽舞台，載入 `../word_style.css` 和 `../shared/word_page.js`。
- `envy.css`：只管本款預覽棋盤格及尺寸，不能替換全站統一 UI。
- `envy_style.js`：共用 UI 的本款設定。
- `envy_template.js`：本款**完全獨立的完整 SVG 繪圖核心**（不是共用的七罪 template）。
- `envy.js`：直式產生器。
- `envy_horizontal.js`：橫式產生器。
- `envy_animated.js`：本款可獨立開啟的直橫動態 SVG 產生器。

全部 SVG 元素跟著 SVG/PNG/書封/動態 SVG 下載；只有網站棋盤格用於檢視，不在輸出內。

所有軍火庫元件都經 `https://lib.stillnessbyslowly.com/` 直接引用，不打包副本。

下載四種模式不加新按鈕：SVG、透明 PNG（2×）、700×1000 書封 PNG、動態 SVG。
