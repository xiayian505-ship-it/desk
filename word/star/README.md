# 星河入夢｜慢慢藝術字

作品代號：`star`　｜　作者：夏熠安　｜　Stillness by Slowly

> 本款以星軌、月牙、寶石、星塵與藍紫粉色流光為主題，提供 1～4 字自由輸入的直式、橫式藝術字；藝術字的顯示名稱為《星河入夢》，程式目錄與介面識別碼仍保留 `star`。

## 一、現行架構與功能

- 共用作品頁：`../shared/word_page.js` 建立標題、輸入區、直橫切換、即時預覽及四個下載位置；共用頁面外觀由 `../word_style.css` 處理。
- `title_style.js` 僅提供 `window.SlowlyWordPageConfig` 設定，不自行重寫輸入和下載操作。
- `title_template.js` 保留本款直式專用的 SVG 星軌／星光／裝飾模板，由 `title.js` 根據輸入的文字產生字形；不是依賴全系列共用材質核心。
- `title_horizontal.js` 使用獨立橫式構圖，不將直式畫面旋轉。
- `title_animated.js` 在現有直橫式輸出上加入 SVG 原生動畫，包括緩慢浮動、星點閃爍與局部光澤變化；動態檔案可獨立播放，不依賴作品頁 CSS 或 JS。
- 目前提供中文及英文文字輸入，最多 4 字元；不提供使用者自訂配色介面。所有主字、星軌與裝飾都會進入匯出的 SVG 畫面。

## 二、輸出規格

| 下載位置 | 直式 | 橫式 |
| --- | --- | --- |
| SVG | 840 × 1200 | 1200 × 760 |
| 透明 PNG（2 倍） | 1680 × 2400 | 2400 × 1520 |
| 書封 PNG | 700 × 1000 | 700 × 1000 |
| 動態 SVG | 840 × 1200 | 1200 × 760 |

- 以上輸出的畫布均為透明背景；頁面預覽的棋盤格不會跟著匯出。
- 直式生成器沿用原星軌內部構圖比例，依 1～4 字調整內部 `viewBox`，再等比置入固定的 840 × 1200 外部畫布。
- SVG 中的字形由 `<text>` 與裝置上的可用字型渲染。因不同系統具備的字型可能不同，SVG 跨裝置開啟時字形可能略有差異；想保留網站上看到的字形可使用輸出的 PNG。
- 動態 SVG 的播放仍取決於開啟它的瀏覽器或檢視工具是否支援 SVG 原生動畫。

## 三、檔案分工

```text
word/star/
├── index.html            # 引用本款與軍火庫函式、提供預覽 template
├── title.css             # 本款預覽樣式
├── title_style.css       # 本款頁面補充樣式
├── title_style.js        # 本款名稱、預設文字、範例及生成器接線
├── title_template.js     # 直式專屬星軌與裝飾 SVG 模板
├── title.js              # 直式 SVG 生成與下載介面
├── title_horizontal.js   # 橫式 SVG 生成與下載介面
├── title_animated.js     # 直式／橫式自足動態 SVG 生成與下載
└── README.md             # 本款說明（本檔）
```

本款沒有必須部署的 `assets/` 資料夾，不需要另行攜帶字型檔。更換作品名稱不改變 `word/star/` 路徑及 `SlowlyStarArt`、`SlowlyStarHorizontalArt`、`SlowlyStarAnimatedArt` 的介面名稱，以避免破壞現行接線。

## 四、相依與部署

`index.html` 透過慢慢軍火庫公開的 HTTPS 絕對 URL 載入現有文字生成、PNG 及 Blob 相關函式，並載入本款 SVG 模板和生成器；**不複製軍火庫原始碼**。若軍火庫必要函式未成功載入，相關生成或下載可能無法工作，不能假設可以完全離線執行。

本款由 GitHub Pages 靜態部署，維持現有相對路徑：`word/star/`。首頁作品名稱和搜尋資料則另外放在 `word/index_data.js`。本次改名只改展示名稱、預設文字、必要的 SVG 標題及輸出檔名，保留既有視覺構圖和下載機制。

## 五、維護注意

- 全系列規則請先讀 `word/word_readme.md`，作品頁接入方式再讀 `word/shared/README.md`。
- 調整畫作時，只改本款生成器、模板與必要樣式；不為了改名而修改共用 UI。
- 作品頁特效與下載 SVG 是兩回事；需要跟著下載的裝飾必須寫入 SVG 本身。
- 若更改輸出規格，應同時確認直式、橫式、PNG、書封與動態 SVG，不以僅能預覽代表下載測試通過。
