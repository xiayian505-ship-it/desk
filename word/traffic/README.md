# 第 47 款｜車水馬龍（Traffic Lettering）

> 本款遵守 `word/word_readme.md` 的全系列固定規則；作品頁沿用 `word/shared/word_page.js`，下載與輸入流程仍由慢慢軍火庫正式 HTTPS 元件處理。本 README 依照使用者提供的 MD 規格，完整保留本次定案的設計構思與交付方向。

## 一、作品設計構思

**名字：** 車水馬龍

**主題意象：** 都市夜景中的霓虹車流。主題重點不是畫寫實街景，而是把「車流不息、夜城繁華、光軌穿梭」凝縮成一款藝術字。整體氣質偏夜城、霓虹、節奏感、流光感；不要變成賽博面板，也不要做成水墨、古風或厚重招牌底板。

**配色：** 主字直接參考軍火庫 **Effects → Light → Electric Border** 原件的預設四種色：`rgb(255, 70, 120)`、`rgb(80, 210, 255)`、`rgb(175, 90, 255)`、`rgb(90, 255, 180)`。不另造「自以為 RGB」的配色。深夜藍字形結構和白亮面保留，四種光色交錯用於外描邊、內部行車線與緩慢流動的字緣掃光。原本上下兩組流光車軌可繼續保留既定亮青藍與暖黃車燈。

**字與字之間：** 四字仍是主體，置於畫面中心。依使用者後續要求，**參考《星河入夢》緊貼、微微交疊的排字感**，讓相鄰文字像夜間車潮互相擠靠，而不是各自站在獨立車道上。直式字距刻意小於字體高度，橫式字距也小於字體寬度；相鄰筆畫互相疊壓，以少量左右錯位與傾斜保住閱讀性。直式與橫式各自排列，不旋轉套版；1～4 字都重新計算字距與尺寸。只參考《星河入夢》的「黏在一起」構圖，**不複製它的星河材質或裝飾**。

**主題線條：** 核心構圖為「中間文字＋上下兩道霓虹流光帶」。上方與下方各有一組長條流光線，像夜間高架道路與地面車軌的抽象化版本，帶少量車道感、虛線節奏、光點尾跡與速度殘影。這兩道線條是主題元素，不是厚底板，也不是單純底線。**不在文字左右增設兩條長弧線；兩側保持開闊留白。**文字本身以軍火庫 Electric Border 的預設四色漸層描邊、RGB 分色內線與淡淡發光打造出都市夜色中的流動感；不自行指定一組假 RGB。

**元素點綴：** 小型光點、方形像素燈、短短的流光切片、星點、遠方車燈粒子與少量霓虹弧線，分散在文字上下與兩側。元素數量要節制，主要服務「車流與城市節奏」，避免塞入過多小汽車圖示或高樓剪影，以免畫面變卡通插圖。

**軍火庫特效（配合設計調整顏色）：**
- **共用文字生成器**：現有 `SlowlyTextGenerator`、`SlowlyHorizontalTextGenerator`、`SlowlyTextGeneratorCore` 仍以軍火庫 HTTPS 原件呼叫，負責字數處理、預覽、SVG／PNG／書封匯出，不在此專案複製零件。
- **Electric Border（預設 RGB）**：已核對官方 `https://lib.stillnessbyslowly.com/effects/light/electric_border.css` 與 `https://lib.stillnessbyslowly.com/effects/light/electric_border_usage.html`。其原生 CSS `.slowly-electric-border.is-active` 是宿主矩形邊框的流光效果，並不是沿文字輪廓走的 RGB 線條；直接套用會多出使用者明確不要的左右邊框，且 `<img>` 中的 SVG 下載無法包含外部 CSS。**因此本款採用它精確的四組預設色，把漸層與 SMIL 動畫實作在自足 SVG 字緣與筆畫中**，而不是宣稱外框元件可直接作用於字形，也沒有複製其 CSS 原始碼。
- **其他零件**：沒有另外引入不必要的 DOM 特效，避免只影響網頁預覽而不包含在下載作品中。

**特殊要求：**
1. 主體構圖要呼應先前定案：**上下各一組霓虹流光帶，中間為「車水馬龍」主字**。
2. 背景透明；不得加整片大底板或厚重色塊，避免與先前多款「底板型」作品重複。左右兩條環繞字體的長弧線已移除，上下流光帶與其短段裝飾保留。
3. 不能做成水墨、山水或古風版；重點是城市霓虹與流動車潮。
4. 靜態 SVG、透明 2× PNG、700 × 1000 書封 PNG、動態 SVG 都要包含完整設計元素，不以網站棋盤格代替背景。
5. 動態 SVG 建議讓上下流光帶與車燈點產生緩慢移動，維持「車流不息」的感覺，但不能讓整個文字亂跳。

## 二、實際繪製與排版

- `traffic_template.js` 直接產生本款的霓虹字體、道路流光、虛線、燈點、城市粒子與動畫，不依賴其他款的模板換色。
- 直式畫布 `840 × 1200`、橫式畫布 `1200 × 760`；透明 PNG 為兩倍輸出，書封為 `700 × 1000`。
- 上下流光帶隨方向重排：橫式時拉寬左右延伸，直式時變成包圍中央文字的上下弧形導流；都維持「上下夾住主字」的設計。普通 SVG 裡的車燈停在光軌上，動態 SVG 才讓車燈行駛，避免靜態檔的光點落在畫布原點。
- 輸入 1、2、3、4 字元都重新計算位置與尺寸，不套死四字版型；兩字以上採用更大的主字、縮小中心距及微小傾斜，形成連續擁擠的霓虹字團。

## 三、接入架構

- `index.html`：沿用慢慢藝術字共用 UI，附 `word-preview-template`，並以 HTTPS 載入軍火庫原件。
- `traffic_template.js`：本款霓虹城市流光的 SVG 模板與動畫。
- `traffic.js`：直式 SVG、透明 PNG、書封 PNG 下載。
- `traffic_horizontal.js`：橫式 SVG、透明 PNG、書封 PNG 下載。
- `traffic_animated.js`：直橫式自足動態 SVG 下載。
- `traffic_style.js`：僅宣告頁面設定、範例與生成器名稱。
- `traffic.css`：僅本款預覽舞台樣式。
- `word/index_data.js`：新增第 47 款目錄資料。

## 四、交付與部署

解壓 ZIP 到 `desk/` 根目錄，保留 `word/traffic/` 路徑；`word/index_data.js` 只新增第 47 款資料，其餘作品維持原狀。手動刪除路徑：**0 個**。
