# 大雪紛飛｜慢慢藝術字

- 英文代號：`snow`
- 預設代表文字：`大雪紛飛`
- 形式：直式＋橫式
- 下載：SVG、透明 PNG、角角者書封 PNG
- 入口網址：`https://desk.stillnessbyslowly.com/word/snow/index.html`

## 設計方向

雪晶、霜霧與冷白冰藍。讓文字落在一場安靜的冬天裡。

## 檔案說明

- `snow.js`：直式藝術字生成
- `snow_horizontal.js`：橫式藝術字生成
- `snow_template.js`：直式 SVG 模板
- `snow.css`：預覽區與主題畫面樣式
- `snow_style.css`：頁面主題補充樣式
- `snow_style.js`：輸入、切換與下載互動
- `index.html`：網站入口
