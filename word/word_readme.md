範例｜電閃雷鳴


---

一、系列基本資料

- 系列代號：thunder
- 建議路徑：desk/word/thunder/
- 系列名稱：電閃雷鳴
- 主要用途：小說標題字 / 書封字 / 氣氛強烈的視覺標題
- 代表文字：電閃雷鳴
- 字數限制：1～4 字
- 排列方式：直式
- 目標平台：手機優先，桌機同步可用
- 是否先做設計稿：是


---

二、視覺定位

- 核心氣質：爆裂、壓迫、冷冽、強能量、瞬間照亮黑夜
- 情緒關鍵字：雷光、風暴、裂痕、轟鳴、危險、張力
- 主要配色：黑、深灰、夜藍
- 輔助配色：冷白、電藍、紫藍
- 亮點色：高亮白藍電光
- 整體明度：偏暗
- 風格傾向：奇幻 × 風暴 × 電能 × 戲劇化
- 與既有系列的差異：
  - 不像 star 那麼夢幻精緻
  - 不像 rain 那麼濕潤詩意
  - 更強烈、更瞬間、更帶破壞感
- 禁止出現的感覺：
  - 不要星空浪漫感
  - 不要水晶字感
  - 不要水墨文藝感太重
  - 不要科技 UI 霓虹感過頭


---

三、文字本體設定

- 字體傾向：偏書法 / 粗筆鋒 / 帶裂痕的力量字
- 筆觸語言：斷裂、爆開、帶電弧切痕
- 文字材質感：雷光灼亮、邊緣炸裂、局部焦痕
- 字體是否可替換：是，但預設要有「力量感」
- 文字是否保留直式：是
- 單字 / 多字時的排版策略：
  - 1 字：放大，讓雷電集中劈向字體中心
  - 2～4 字：上下排列，每字之間用電弧或裂光串聯
- 文字主體效果：
  - 強描邊
  - 外發光
  - 裂紋
  - 電弧分岔
  - 少量煙霧 / 燒灼邊


---

四、裝飾元素設定

- 主要裝飾元素：
  - 閃電分岔
  - 電弧
  - 爆光
  - 雲層裂光
- 次要裝飾元素：
  - 火花
  - 細碎亮點
  - 煙霧
  - 裂紋碎片
- 背景氣氛元素：
  - 烏雲
  - 暗夜
  - 霧
  - 隱約雷雨感
- 是否需要動態預覽：要
- 動態只存在於網站預覽，還是也要影響輸出設計語言：
  - 預覽可有閃爍 / 微電流
  - 輸出為靜態，但保留「剛剛閃過」的構圖感
- 透明輸出時要保留哪些裝飾：
  - 文字本體
  - 電弧
  - 爆光
  - 局部煙霧
- 透明輸出時不能帶出的背景：
  - 大片天空
  - 地景
  - 雲海底圖
  - 實景建築


---

五、軍火庫 / 機制規劃

- 可直接使用的軍火庫零件：
  - effects/light/glow.css
  - effects/light/electric_border.css
  - effects/celebration/flash_shake.css
  - PNG 下載零件
  - Canvas PNG 零件
- 需要新寫但未必進軍火庫的部分：
  - 雷電字體專用 SVG 裂光模板
  - 電弧繞字路徑
- 有機會抽成軍火庫的新零件：
  - 文字周圍的 lightning arc generator
  - 電閃脈衝效果
- 宿主頁面控制哪些外觀：
  - 背景配色
  - 介面風格
  - 區塊排版
- 生成引擎控制哪些行為：
  - 文字佈局
  - 電弧與裂光裝飾位置
  - SVG / PNG 輸出


---

六、網站功能需求

- 輸入方式：輸入框，限 1～4 字
- 即時預覽：要
- 範例按鈕：
  - 電閃雷鳴
  - 驚雷
  - 裂光
- 下載格式：
  - SVG
  - 透明 PNG
  - 角角者書封 PNG
- 特定書封格式：700 × 1000
- 下載檔名規則：
  - 文字_thunder.svg
  - 文字_thunder_2x.png
  - 文字_角角者書封_700x1000.png
- 手機版要求：
  - 按鈕可直排或滿版
  - 不橫向溢出
- 是否需保留透明棋盤格預覽：要
- 是否需系列說明 / 使用說明 / 字型授權提醒：要，保留簡短版


---

七、輸出規格

- 標準 SVG 尺寸：例如 840 × 1200
- 標準 PNG 尺寸：例如 1680 × 2400
- 角角者書封尺寸：700 × 1000
- 背景要求：透明
- 是否允許另外輸出有底圖版本：先不要
- 裝飾元素輸出原則：
  - 文字本體一定保留
  - 雷電裝飾可保留
  - 背景實景不可輸出進透明版
