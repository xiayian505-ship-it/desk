# 慢慢藝術字｜設計與交付規則

> 適用範圍：`desk/word/` 的藝術字系列。  
> 用途：每次新增或精修一款藝術字時，先說清楚作品的視覺設計；既有網站功能、檔案分工及交付標準則依本文件執行，不必每次重複填寫。  
> 原則：**使用者決定文字內容；每款藝術字保有作者設定的配色與風格。**

---

## 一、每次提供的設計需求（可直接複製填寫）

以下八項是**作品設計**，不是要求重新建置整個網站。可以用自然語言描述；沒有指定的細節先討論，不擅自補成定案。

```text
名字：

主題意象：
（作品核心意象、整體氣質；想避免的感覺可一起寫。）

配色：
（主色、輔色、漸層、亮部、描邊、陰影；沒有要求就不開放使用者調色。）

字與字之間：
（要連接、交疊、斷開還是留白？位置、大小、前後層級、方向。）

主題線條：
（字體筆畫／填色／雙層外框／斷口／流線／箭頭等；哪些壓在字上或字下。）

元素點綴：
（形狀、尺寸、數量、散布範圍、透明度、前後層級；是否跟文字一起輸出。）

軍火庫特效（配合設計調整顏色）：
（填特效的正式名稱，以及「用在什麼元素上」；不要只列名稱。）

特殊要求：
（這一款獨有的規則，例如直橫版不同構圖、動畫順序、禁止的元素。）
```

**可直接附在需求末尾：**「其餘沿用《慢慢藝術字｜設計與交付規則》；所有元素都要隨作品下載，背景透明。」

### 描述時最有用的細節

- **相對位置**：例如「第一、二字之間偏上方」「第三、四字之間偏下方」。
- **比例**：例如「羽毛高度約為主字的一半」「流線在第一字高度的三分之一處」。
- **圖層**：例如「線壓在字上」「裝飾在字下，保持高透明度」。
- **方向與延伸**：例如「斜線從首字上方一路延伸到末字下方，兩端皆有箭頭」。
- **特效用途**：例如「Shine Text 作用在字體填色」，而非只寫「加入 Shine Text」。

## 二、全系列固定規則（不必每次重寫）

### 1. 文字輸入與排版

- 輸入 **1～4 個字元**，可用中文或英文；按既有文字生成器規則處理。
- **直式與橫式**都要支援，兩種排列各自調整構圖，不直接把同一張畫面旋轉。
- 輸入 1、2、3、4 字元時，字距、主裝飾與構圖需合理適應；不能只針對四字範例設計。
- 預設文字內容與顏色分工固定：使用者輸入文字，**作品配色由本款設計決定**，不額外加入調色介面。
- 使用可合法使用的字型，避免授權不明的素材；字型顯示與輸出須考量裝置差異。

### 2. 網站與預覽

- 沿用 `desk/word/` 現有作品頁的**統一 UI**，不因新款另外設計一套操作介面。
- 保留即時預覽、直／橫切換、範例文字、下載區、透明棋盤格及手機版操作。
- 網站標題遵守全系列一致的樣式；**不加裝飾點、不擅自替頁面標題加底線或特效**。
- 網站頁尾保留「慢 慢 | Stillness by Slowly」。
- 主頁新增作品時，只需加入目錄資料、對應入口與必要視覺色票；作品簡介維持**短文案**，不額外增加長篇敘述。
- 網頁背景只用於**檢視輔助**；不能以「預覽看得到」代替「下載包含該元素」。

### 3. 必備下載模式

| 格式 | 預設尺寸／要求 |
| --- | --- |
| SVG | 直式 `840 × 1200`；橫式 `1200 × 760`，背景透明 |
| 透明 PNG | 直式 `1680 × 2400`；橫式 `2400 × 1520`（2×） |
| 角角者書封 PNG | `700 × 1000`，完整作品置入透明畫布 |
| 動態 SVG | 直式／橫式皆支援，動畫包含於 SVG 自身，不依賴網站頁面樣式 |

- **完整輸出是預設**：主字、筆畫效果、描邊、線條、裝飾、粒子、羽毛、光暈及其他被指定為作品內容的元素，必須全部跟著 SVG／PNG／書封一起輸出。
- **動態 SVG** 需包含上述所有元素，並保留作品設定的動畫；一般 SVG／PNG／書封則呈現完整、可獨立使用的靜態畫面。
- 不把棋盤格、純展示用的網站背景或網站 UI 一起輸出；**輸出畫布保持透明**。
- 不可把效果只做在預覽 DOM 或 CSS 背景，卻讓匯出只剩文字。如果某效果無法用自足 SVG 重現，須先明確告知並討論替代方案。
- 以上是**新款與精修款的交付標準**；既有基礎款不因此視為全部已完成，之後按需求逐款補齊。

### 4. 軍火庫使用原則

- 軍火庫公開入口：`https://lib.stillnessbyslowly.com/`。
- 已有的共用功能或特效，優先使用**軍火庫正式的 HTTPS 絕對 URL 直接引用**；不複製軍火庫 JS／CSS 原始碼，不建立副本資料夾。
- **先核對原件的使用方式**，再接入；不依名稱猜檔案路徑、API、CSS class 或參數。
- 軍火庫負責機制，**宿主作品控制配色、字體、尺寸、位置與整體外觀**。
- **網站特效與匯出是兩件事**：若軍火庫提供的是 DOM／CSS／Canvas 特效，網站端仍引用軍火庫原件；下載端由該作品製作可獨立顯示的 SVG 表現，不把軍火庫零件複製進專案。
- **共用元素／抽離軍火庫的進一步規劃另案討論**；此文件不決定要抽哪些零件，也不為抽離而重構現有專案。

### 5. 檔案分工與部署

新作品目錄預設為 `desk/word/<系列代號>/`，依責任分檔，例如：

```text
word/<系列代號>/
├── index.html
├── <代號>.css             # 作品本體／預覽必要樣式
├── <代號>.js              # 直式生成
├── <代號>_horizontal.js   # 橫式生成
├── <代號>_template.js     # SVG 畫面與裝飾元素
├── <代號>_animated.js     # 動態 SVG（需要時獨立）
├── <代號>_style.css       # 本款 UI 外觀差異（需要時）
├── <代號>_style.js        # 網頁 UI 互動
└── README.md             # 本款說明
```

- 以上是**責任分工示例**；若既有系列使用不同檔名或組織方式，以最新提供的實際檔案為準，不為了湊檔案數而重構。
- 新增作品要同步更新首頁 `word/index_data.js`，以及需要的 `word/index_style.css` 色票樣式；**不重寫 A～Z 分頁、搜尋或共用下載邏輯**。
- 只修改本次需要的檔案，保留其他作品及既有功能，**不得以舊版本覆蓋較新的網站變更**。
- 程式碼保持易讀、完整縮排，不交付壓縮成一行的原始碼。
- 交付**可部署 ZIP**，維持與 `desk/word/` 一致的相對路徑，列明新增與修改檔案。

### 6. 交付前檢查

- [ ] 1／2／3／4 字元正常顯示；直式、橫式可切換。
- [ ] 字體與漸層能正常渲染，無空白字、截斷或 SVG 格式錯誤。
- [ ] 作品內所有指定元素都存在於**匯出 SVG 本體**，不是只在網站預覽裡。
- [ ] 透明 PNG、700 × 1000 書封 PNG 的實際圖片含有完整設計，背景透明。
- [ ] 動態 SVG 可在支援 SVG 動畫的瀏覽器中播放；靜態輸出仍完整。
- [ ] 360～390px 手機版沒有橫向溢出，輸入、切換、下載按鈕可操作。
- [ ] 軍火庫路徑已核對，沒有複製共享程式碼。
- [ ] 主頁入口與新檔案路徑正確，不覆蓋其他系列的最新修改。
- [ ] 如無法完成某一項，交付時**如實註明**，不可僅以程式碼檢查通過宣稱所有下載實測成功。

## 三、設計需求範例｜黑羽舞動

以下示範的是**如何交代視覺需求**，不是要求其他款複製《黑羽舞動》的風格。

**名字：** 黑羽舞動

**主題意象：** 黑色實心羽毛；冷冽、銳利、有動勢。

**配色：** 黑色、淺黑、灰色、白色、淺灰與黑色漸層；文字填色有低彩度炫彩光澤。

**字與字之間：** 從「黑」字上方開始，以一條斜向長線穿過文字，一路延伸至「動」字下方。首尾都設箭頭，形成**壓在字上的單條雙箭頭**；橫式也依四字構圖調整。

**主題線條：** 字體外框採雙層斷裂線，兩層斷口錯位，不是實心完整框；字體本身使用炫彩漸層。

**元素點綴：** 黑色實心羽毛高透明度、錯位散布；以四字構圖下方約三分之二的區域為主要分布範圍，避免遮住文字主體。

**軍火庫特效（配合設計調整顏色）：**

- **Gold Rain**：用於銀灰色粒子點綴。
- **Shine Text**：用於字體填色的光澤效果。
- **Minimal Underline**：參考其 70% 線長／展開概念，作用在**作品字體的斷裂外框**，不是網站標題下方。

**特殊要求：** 靜態 SVG、動態 SVG、透明 PNG、書封 PNG **全部包含完整作品**；背景透明。其餘沿用全系列固定規則。
