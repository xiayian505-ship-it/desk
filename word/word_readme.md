# 慢慢藝術字｜設計與交付規則

> 適用範圍：`desk/word/` 的藝術字系列。  
> 用途：每次新增或精修一款藝術字時，先說清楚作品的視覺設計；既有網站功能、檔案分工及交付標準則依本文件執行，不必每次重複填寫。  
> 原則：**使用者決定文字內容；每款藝術字保有作者設定的配色與風格。**  
> **閱讀優先順序：收到新的 `word/` ZIP 或接手此專案，先讀本檔，再按任務讀 `word/shared/README.md` 和必要的作品檔案。**

---

## 零、接手時的閱讀順序（請優先遵守）

此文件是 **`desk/word/word_readme.md`**，為全系列設計與交付規則的**第一閱讀入口**。它不是自動注入新對話的設定；每次收到 ZIP 或接手開發，**請先主動開啟此檔**，再依任務定位程式。

1. **先確認版本基底**：以使用者**本次指定、最新提供的 ZIP／檔案**為準；不能拿比較舊的 GitHub 版或先前 ZIP 覆蓋它。若使用者指定 GitHub 版才以該版本為準。
2. **先讀這份規則**：`word/word_readme.md`，確認設計格式、輸出規格及禁止擅動範圍。
3. **涉及作品頁或新增作品，再讀**：`word/shared/README.md`，確認共用 UI 的接入規格及讀檔路線。
4. **只讀任務所需檔案**；不必每次讀完 33 款（或未來更多款）的全部生成器。若是共用功能問題、跨款相依或變更影響面不明，才擴大檢查相關作品。

| 任務 | 優先檢查的檔案 | 不需一開始就讀的部分 |
| --- | --- | --- |
| 精修單一藝術字 | `word/<代號>/` 的模板、生成器、CSS、設定；必要時 `word/shared/README.md` | 其餘所有作品的完整程式 |
| 新增藝術字 | 本檔、`word/shared/README.md`、共用 UI 接入範例、主頁目錄資料 | 逐款重寫 HTML／UI 或掃描全部作品 |
| 修改全系列作品頁 UI | `word/shared/word_page.js`、`word/word_style.css`、必要的作品設定與預覽模板 | 各款 SVG 繪圖核心 |
| 修改單款特殊預覽 | 該款的預覽舞台、CSS、`_style.js` 特效接線 | 其他作品的專屬特效 |
| 修改藝術字首頁 | `word/index.html`、`word/index_data.js`、`word/index_style.css` 與相關首頁 JS | 各款生成器 |
| 修改「慢慢看」說明文字 | `word/index_notes.json` | HTML、搜尋分頁、各款作品 JS |
| 修改檢視工具入口／SVG 檢視室說明 | `word/viewer_content.json`；必要時 `word/svg-viewer/viewer_content.js` | 藝術字生成器、檢視核心 `viewer.js` |
| 修改下載的操作介面 | `word/shared/word_page.js`、`word/shared/README.md` | 未受影響的作品模板 |
| 修改下載檔的實際畫面或內容 | 該款 SVG 模板、生成器、匯出流程、必要的軍火庫元件 | 不相關的作品頁 UI |
| 修改 SVG 檢視室 | `word/svg-viewer/`，需要時再查首頁入口 | 全部藝術字繪圖核心 |

**分工底線：共用頁面只處理 UI 與接線；各款作品控制字體、視覺、SVG 模板、特效和輸出內容。** 不要在單款重新實作整套 UI，也不要為了修改共用 UI 順便調整已可用的藝術字。

## 一、每次提供的設計需求（可直接複製填寫）

以下八項是**作品設計**，不是要求重新建置整個網站。可以用自然語言描述；沒有指定的細節先討論，不擅自補成定案。

```text
名字：

主題意象：
（作品核心意象、整體氣質；想避免的感覺可一起寫。）

配色：
（主色、輔色、漸層、亮部、描邊、陰影；沒有要求就不開放使用者調色。）

字與字之間：
（要連接、交疊、斷開還是留白？位置、大小、前後層級、方向。）

主題線條：
（字體筆畫／填色／雙層外框／斷口／流線／箭頭等；哪些壓在字上或字下。）

元素點綴：
（形狀、尺寸、數量、散布範圍、透明度、前後層級；是否跟文字一起輸出。）

軍火庫特效（配合設計調整顏色）：
（填特效的正式名稱，以及「用在什麼元素上」；不要只列名稱。）

特殊要求：
（這一款獨有的規則，例如直橫版不同構圖、動畫順序、禁止的元素。）
```

**可直接附在需求末尾：**「其餘沿用《慢慢藝術字｜設計與交付規則》；所有元素都要隨作品下載，背景透明。」

### 描述時最有用的細節

- **相對位置**：例如「第一、二字之間偏上方」「第三、四字之間偏下方」。
- **比例**：例如「羽毛高度約為主字的一半」「流線在第一字高度的三分之一處」。
- **圖層**：例如「線壓在字上」「裝飾在字下，保持高透明度」。
- **方向與延伸**：例如「斜線從首字上方一路延伸到末字下方，兩端皆有箭頭」。
- **特效用途**：例如「Shine Text 作用在字體填色」，而非只寫「加入 Shine Text」。

## 二、全系列固定規則（不必每次重寫）

### 1. 文字輸入與排版

- 輸入 **1～4 個字元**，可用中文或英文；按既有文字生成器規則處理。
- **直式與橫式**都要支援，兩種排列各自調整構圖，不直接把同一張畫面旋轉。
- 輸入 1、2、3、4 字元時，字距、主裝飾與構圖需合理適應；不能只針對四字範例設計。
- 預設文字內容與顏色分工固定：使用者輸入文字，**作品配色由本款設計決定**，不額外加入調色介面。
- 使用可合法使用的字型，避免授權不明的素材；字型顯示與輸出須考量裝置差異。

### 2. 網站與預覽

- 沿用 `desk/word/` 現有作品頁的**統一 UI**：共用控制器是 `word/shared/word_page.js`，統一樣式是 `word/word_style.css`。不得在新款重寫一套介面。
- 作品的 `index.html` 保留必要的 script / stylesheet 引用與 `<template id="word-preview-template">` 專屬預覽舞台；由共用控制器建立操作頁。`<代號>_style.js` 只宣告作品設定與必要特效回呼。
- 保留即時預覽、直／橫切換、範例文字、下載區、透明棋盤格及手機版操作。
- 各款作品頁的標題遵守全系列一致的樣式；**不加裝飾點、不擅自替作品頁標題加底線或特效**。主頁「慢慢藝術字」則經使用者另行定案：以軍火庫 `effects/typography/shine_text.css` 套流動漸層，宿主設定陰影與色票；主頁副標由 `index_notes.json` 取文案，以軍火庫 `effects/typography/marquee.css` 循環橫移。兩項原件一律 HTTPS 引用，不複製入專案；副標只循環原本的文字，不加入星號或裝飾符號。首頁標題不放 Enso 圓環。
- 全站頁尾左右統一：左側「慢 慢 | Stillness by Slowly」連結 `https://stillnessbyslowly.com/`，右側「夏熠安」以純文字連結 `https://www.threads.com/@xiayian505`；不放箭頭、社群圖示或引導文字。共用樣式由 `word/shared/footer.css` 管理。
- 主頁新增作品時，只需加入目錄資料、對應入口與必要視覺色票；作品簡介維持**短文案**，不額外增加長篇敘述。
- 主頁網址分享預覽：`word/index.html` 內的 Open Graph / Twitter Card 標籤指定預覽標題「慢慢藝術字」、副標「讓想說的話，成為心動的模樣」，封面（1200 × 630）使用自有圖床 HTTPS 外連 `https://img.stillnessbyslowly.com/images/2026/10/df1287c2-7dcf-4632-b318-453b4aa58aec_slowly-word-share.png`，不存入 GitHub 儲存庫。分享圖是**靜態圖片**；網頁標題的 Shine Text、Marquee 等動態效果仍由既有軍火庫與宿主處理。分享平台可能快取預覽，部署後不保證立即更新。
- 「慢慢看」六項說明文字從 `word/index_notes.json` 讀取；01～03 是授權條款，04「展現心動模樣」、05「寄放心動模樣」、06「製作心動模樣」是作品說明。外層六項使用軍火庫 TreeSelection 互斥收合；05 由 JSON 的 `formats` 陣列建立 SVG／PNG 內層互斥收合，內部的 `variants` 只作為一般小標題。新增 GIF、MPEG 等格式，先加資料，再確認下載功能是否真的提供，不能因說明新增而宣稱已支援。
- 檢視室入口清單與 SVG 檢視室說明從 `word/viewer_content.json` 讀取。**僅改文案時只改對應 JSON**，除非介面結構真的改變。
- 作品目錄已在 `word/index_data.js` 獨立管理；新增作品只加資料，不把作品卡片寫回 `index.html`。
- 網頁背景只用於**檢視輔助**；不能以「預覽看得到」代替「下載包含該元素」。

### 3. 必備下載模式

| 格式 | 預設尺寸／要求 |
| --- | --- |
| SVG | 直式 `840 × 1200`；橫式 `1200 × 760`，背景透明 |
| 透明 PNG | 直式 `1680 × 2400`；橫式 `2400 × 1520`（2×） |
| 書封 PNG | `700 × 1000`，完整作品置入透明畫布 |
| 動態 SVG | **第四個下載位置固定預留**；該款有可用動畫生成器時啟用。新款或精修完成款的動態檔應自足，直式／橫式皆應支援 |

- **下載區固定四個按鈕與順序**：SVG、透明 PNG、書封 PNG、動態 SVG；按鈕上不再顯示「角角者」，但內部下載函式名稱及既有輸出檔名不因此重寫。尚未完成動畫的舊款也顯示第四個按鈕，但必須停用、不可假下載；完成該款的動態生成器後才啟用。
- **有四個按鈕不代表全部舊款已經有動態 SVG**；不因介面統一而擅自補動畫或改寫既有設計。
- **完整輸出是預設**：主字、筆畫效果、描邊、線條、裝飾、粒子、羽毛、光暈及其他被指定為作品內容的元素，必須全部跟著 SVG／PNG／書封一起輸出。
- **動態 SVG** 需包含上述所有元素，並保留作品設定的動畫；一般 SVG／PNG／書封則呈現完整、可獨立使用的靜態畫面。
- 不把棋盤格、純展示用的網站背景或網站 UI 一起輸出；**輸出畫布保持透明**。
- 不可把效果只做在預覽 DOM 或 CSS 背景，卻讓匯出只剩文字。如果某效果無法用自足 SVG 重現，須先明確告知並討論替代方案。
- 以上是**新款與精修款的交付標準**；既有基礎款不因此視為全部已完成，之後按需求逐款補齊。

### 4. 軍火庫使用原則

- 軍火庫公開入口：`https://lib.stillnessbyslowly.com/`。
- 已有的共用功能或特效，優先使用**軍火庫正式的 HTTPS 絕對 URL 直接引用**；不複製軍火庫 JS／CSS 原始碼，不建立副本資料夾。
- **先核對原件的使用方式**，再接入；不依名稱猜檔案路徑、API、CSS class 或參數。
- 軍火庫負責機制，**宿主作品控制配色、字體、尺寸、位置與整體外觀**。
- **網站特效與匯出是兩件事**：若軍火庫提供的是 DOM／CSS／Canvas 特效，網站端仍引用軍火庫原件；下載端由該作品製作可獨立顯示的 SVG 表現，不把軍火庫零件複製進專案。
- **共用元素／抽離軍火庫的進一步規劃另案討論**；此文件不決定要抽哪些零件，也不為抽離而重構現有專案。

### 5. 檔案分工與部署

目前的**正式共用架構**如下（新增作品依此接入，不要沿用舊版每款重寫 UI 的做法）：

```text
word/
├── word_readme.md                # 本檔：設計與交付規則、接手第一入口
├── word_style.css                # 全系列作品頁 UI 樣式
├── shared/
│   ├── README.md                 # 共用 UI 接入說明、程式閱讀指南
│   └── word_page.js              # 共用作品頁 HTML／操作控制器
├── index.html                    # 藝術字系列首頁
├── index_data.js                 # 首頁作品資料
├── index_notes.json              # 慢慢看主體說明與使用提醒
├── viewer_content.json           # 檢視室入口模式清單及說明
├── index_content.js              # 只讀取兩份 JSON 並填入首頁
├── index_style.css               # 首頁樣式
├── svg-viewer/                   # SVG 檢視室：獨立工具、viewer_content.js 讀取說明 JSON
└── <系列代號>/
    ├── index.html                # 共用頁所需引用 + 本款預覽 template
    ├── <代號>.css                 # 本款預覽／效果必要樣式
    ├── <代號>.js                  # 本款直式生成器
    ├── <代號>_horizontal.js       # 本款橫式生成器（若有）
    ├── <代號>_template.js         # 本款 SVG 畫面與裝飾（若有）
    ├── <代號>_animated.js         # 本款動態 SVG（未完成可無）
    ├── <代號>_style.css           # 本款特殊預覽樣式（必要時）
    ├── <代號>_style.js            # 作品設定；特殊預覽回呼（必要時）
    └── README.md                 # 本款記錄（若有）
```

- 說明資料分成 **兩個 JSON**：`index_notes.json` 是主體說明；`viewer_content.json` 是檢視模式入口與檢視室介紹。JSON 只改文字／入口設定，互動邏輯仍留在 JS。檢視模式增加時先新增對應頁面與功能，再將入口加入 `modes`；新增 JSON 不能自行生成新工具。
- 主頁 01～06 說明列表由 `index_content.js` 依 `index_notes.json` 建立，預設全部收合；標題文字留空，但 `.notes-heading` 須保留原本的標題高度及間距，不得讓清單往上移。以軍火庫 `https://lib.stillnessbyslowly.com/state/tree_selection.js` 的 `TreeSelection.create({ expansion: "single" })` 管理互斥展開。授權條文維持正式書面用語，文字調整只修改 JSON，不將 Tree 零件原始碼複製到宿主。
- **正式路徑是 `word/shared/`，不是 `word/_shared/`**。GitHub Pages 預設 Jekyll 可能忽略 `_` 開頭的資料夾；不要重新引入 `_shared/` 作為瀏覽器載入目錄。
- 每款的 `_style.js` **不再重複實作共用 UI**，僅提供 `window.SlowlyWordPageConfig` 與必要的專屬特效接線；格式以 `word/shared/README.md` 為準。
- 一般作品 HTML 維持共用頁所需引用，作品獨有預覽結構留在 `word-preview-template`；不要把完整的標題／輸入／下載／頁尾 HTML 複製回每款。
- 這是結構示意，**不表示每款都必須有以上所有檔案**；舊款有不同檔名或實作方式，依最新指定版本查實，不為湊數量而重構。
- 新增作品要同步更新首頁 `word/index_data.js`，以及需要的 `word/index_style.css` 色票樣式；**不重寫 A～Z 分頁、搜尋或共用下載邏輯**。
- 只修改本次需要的檔案，保留其他作品及既有功能，**不得以舊版本覆蓋較新的網站變更**。
- 程式碼保持易讀、完整縮排，不交付壓縮成一行的原始碼。
- 手機 ZIP 覆蓋**不會自動刪除舊檔**：交付可部署 ZIP 時必須列出「需要手動刪除的路徑」，即使為零也明確寫出；不在未告知的情況下假設刪檔會同步。
- ZIP 維持與 `desk/word/` 一致的相對路徑，清楚說明要覆蓋到 repo 的哪一層；文件更新時優先做只包含 MD 的小包，避免用舊版全站覆蓋新檔。

## 三、設計需求範例｜黑羽舞動

以下示範的是**如何交代視覺需求**，不是要求其他款複製《黑羽舞動》的風格。

**名字：** 黑羽舞動

**主題意象：** 黑色實心羽毛；冷冽、銳利、有動勢。

**配色：** 黑色、淺黑、灰色、白色、淺灰與黑色漸層；文字填色有低彩度炫彩光澤。

**字與字之間：** 從「黑」字上方開始，以一條斜向長線穿過文字，一路延伸至「動」字下方。首尾都設箭頭，形成**壓在字上的單條雙箭頭**；橫式也依四字構圖調整。

**主題線條：** 字體外框採雙層斷裂線，兩層斷口錯位，不是實心完整框；字體本身使用炫彩漸層。

**元素點綴：** 黑色實心羽毛高透明度、錯位散布；以四字構圖下方約三分之二的區域為主要分布範圍，避免遮住文字主體。

**軍火庫特效（配合設計調整顏色）：**

- **Gold Rain**：用於銀灰色粒子點綴。
- **Shine Text**：用於字體填色的光澤效果。
- **Minimal Underline**：參考其 70% 線長／展開概念，作用在**作品字體的斷裂外框**，不是網站標題下方。

**特殊要求：** 靜態 SVG、動態 SVG、透明 PNG、書封 PNG **全部包含完整作品**；背景透明。其餘沿用全系列固定規則。
