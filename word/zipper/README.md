# 開闔之間｜慢慢藝術字（zipper v2）

- 主題方向：拉鍊開合、緊貼交錯的字距、整體銀灰切色與少量鏈環點綴。
- 路徑：`word/zipper/index.html`
- 字數：1～4 字；直式 840×1200 SVG / 1680×2400 透明 PNG
- 橫式：1200×760 SVG / 2400×1520 透明 PNG
- 書封：700×1000 透明 PNG
- 動態：純靜態，第四個按鈕維持停用。
- 共用頁：沿用 `word/shared/word_page.js`。
- 本款已改為獨立 SVG 模板：`zipper_template.js` 自行處理字體、拉鍊、鏈環與金屬切色，不再依賴 `word_material_core.js` 的舊版拉鍊材質邏輯。

## 設計重點

- 直式：整體 **左右切色**，四字上下交錯、字距極近。
- 橫式：整體 **上下切色**，四字高低交錯、彼此幾乎貼合。
- 主體一定是字本身；拉鍊穿過文字中央，鏈環只作為輔助點綴。
- 下載輸出必須保留：黑色外框、銀灰金屬、炫彩冷光、拉鍊、鏈環與透明背景。
