# 鳥語花香｜慢慢藝術字

- 英文代號：`bloom`
- 預設代表文字：`鳥語花香`
- 形式：直式＋橫式
- 下載：SVG、透明 PNG、角角者書封 PNG
- 入口網址：`https://desk.stillnessbyslowly.com/word/bloom/index.html`

## 設計方向

花枝、飛鳥與柔亮春色。讓文字像正要開花。

## 檔案說明

- `bloom.js`：直式藝術字生成
- `bloom_horizontal.js`：橫式藝術字生成
- `bloom_template.js`：直式 SVG 模板
- `bloom.css`：預覽區與主題畫面樣式
- `bloom_style.css`：頁面主題補充樣式
- `bloom_style.js`：輸入、切換與下載互動
- `index.html`：網站入口
