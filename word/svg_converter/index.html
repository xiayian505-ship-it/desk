格式限制與使用提醒

支援常見 SVG 原生動畫及 CSS 動畫；複雜濾鏡、路徑變形、外部字型與特殊動畫不保證完整轉換。

影片輸出視目前瀏覽器的 MediaRecorder 格式支援而定。轉換期間請保持分頁在前景，不要鎖定螢幕。

有動畫的 SVG 若擷取到完全相同的影格，轉檔器會停止並顯示原因，避免輸出看似成功卻不會動的檔案。
