# 第 48 款｜星象萬千（Asterism Lettering）

> 本款遵守 `word/word_readme.md` 全系列固定規則；作品頁沿用 `word/shared/word_page.js`。本款 SVG 模板自行繪圖，軍火庫機制與 CSS 均透過正式 HTTPS 直接引用、不複製原始碼。

## 一、作品設計構思

**名字：** 星象萬千

**主題意象：** 以北斗七星作為星圖骨架，呈現古典天文觀測、星象秩序、星宿軌跡與仰望天幕的靜謐壯闊感。A 類英文代號 **Asterism**，意為可辨識的星群圖案；不做一般夢幻銀河或極光，不跟《星河入夢》《極光漫舞》重複。七顆主星必須構成可辨識的斗身與斗柄，不能僅當作隨機光點。

**配色：** 星空墨藍（#152d46）作字形內部支撐，字面為銀白、霧藍、淡金與冷青的明暗漸層；北斗七星用暖銀白與淺金做最亮的主星，細線用冷青轉淡金，刻度與背景星點保持低飽和、低透明度。畫布全透明，不畫大塊深藍背景，不用明亮桃粉、彩虹極光色。

**字與字之間：** 主字是主體，既清楚可讀又有少量角度錯位，直式上下排、橫式水平展開，各用自己的座標與字級；1～4 字依數量重新定位，最多四字。星圖在字的前景與文字交錯，七顆主星突出，但不整片遮蔽文字。字距不使用《車水馬龍》的擠壓式黏連，這款是測天儀式感的留白秩序。

**主題線條：** 北斗七星斗身用 α→β→γ→δ→α 四點閉合，斗柄從 δ→ε→ζ→η，七顆主星與連線一組跨越四字。主星以多層柔光、四向細芒、銀白星核與微金描邊表現；連線為細緻冷青至淡金漸層，避免粗重幾何框。字體使用銀藍錫箔般的冷色漸層、很薄的金銀邊、內部六組刻紋及從筆畫穿過的微弱掃光。畫面上下另有淡淡弧形經緯線與刻度，以非封閉觀測弧環托住文字，不加入大底板。

**元素點綴：** 星群外周疏落的微小銀藍、金色觀測星點、細短刻度與少量星軌；七顆主星要明顯比輔助星點亮。左右弧線與四周註記文字皆不保留，畫面只留下上下觀測弧與核心星圖。星圖背景不是棋盤格，全部裝飾皆是 SVG 內容並隨作品下載。

**軍火庫特效（配合設計調整顏色）：**
- **Basic Glow**，正式路徑 `https://lib.stillnessbyslowly.com/effects/light/glow.css`：作用於作品預覽圖，提供非常輕的冷青輪廓發光，透過 `.slowly-glow.is-active` 及宿主 CSS 變數控制顏色、大小、透明度。**匯出端**由本款 SVG 的柔光濾鏡 `asterism-letter-halo` 與 `asterism-soft-light` 繪成，不依賴外部 CSS；文字、主星和線條在 PNG / SVG / 書封中均保留。
- **共用文字生成器**，軍火庫 HTTPS 的 `SlowlyTextGenerator`、`SlowlyHorizontalTextGenerator` 與 `SlowlyTextGeneratorCore`：處理 1～4 字、直橫式、四種下載與文字標準化。不複製任何共用 JS。

**特殊要求：** 北斗七星必須真的有七顆且連線正確；直式與橫式不能互相旋轉套版；靜態 SVG、透明 PNG、700×1000 書封 PNG 都含完整字型銀藍光澤、星圖、光芒、刻度。動態 SVG 要自足，讓七顆主星以不同相位緩慢呼吸、背景星點間歇閃爍、字內掃光慢慢游移、星圖虛線徐行，不讓主字大幅搖晃；透明背景，無整片底板。任何預覽效果都不得在下載時消失。

## 二、實際繪製與規格

- 本款以 `asterism_template.js` 各自建構直／橫式的字位、北斗星座與觀測弧線。七顆主要星點對應希臘字母 α、β、γ、δ、ε、ζ、η；畫面不再放置額外註記文字，僅保留核心星圖與上下弧線。斗身四角封閉，斗柄三節延伸。
- SVG：直式 **840×1200**、橫式 **1200×760**，底色透明；透明 PNG：**1680×2400**、**2400×1520**；書封 PNG：**700×1000** 完整置入透明畫布；動態 SVG：同直橫畫布尺寸，自足 SMIL 動畫。
- 作品頁與匯出共用完全同一個 SVG 繪圖模板；預覽使用動畫版 SVG，普通輸出使用靜態版，自主匯出不連上特效 CSS 也能保留星光。文字可輸入 1～4 字元，範例預設《星象萬千》、兩字《星圖》《天象》。

## 三、作品檔案

- `index.html`：共用 UI、HTTPS 軍火庫接入、專屬預覽 template。
- `asterism.css`：本款預覽舞台與 Basic Glow 參數；不承擔作品的實際圖像。
- `asterism_template.js`：專屬星圖、主字、七星、刻度、所有 SVG 光效與 SMIL 動畫。
- `asterism.js`：直式 SVG、透明 PNG、書封 PNG 生成器及預覽。
- `asterism_horizontal.js`：橫式生成器及預覽。
- `asterism_animated.js`：直橫式自足動態 SVG。
- `asterism_style.js`：只宣告共用頁面設定與三個範例。
- `README.md`：完整設計構思、軍火庫引用及使用規格。
- `word/index_data.js`：在現有 47 款基底上新增第 48 款卡片，其餘索引資料不變。
