# 唯我獨尊｜Pride Lettering・重製版

## 本款專屬的藝術設計

- **主題**：七宗罪的傲慢。與其他七宗罪沒有視覺系列模板，也不與舊有 37 款共用藝術字繪圖核心。
- **構圖**：文字本身是逐級居高、向右下遞減的金屬高塔。若輸入文字裡含有「我」，則由「我」站上最高位、成為最大字，王冠也會懸在「我」的上方；其餘字再依序縮小與下降。直式為陡峭俯視，橫式為向右下遞減的階序，兩個方向單獨編排。
- **色系**：冰白銀金屬、霜金細線、深藍紫立體側面，拒絕帝王暖金的旗幟與卷軸氣質。
- **元素**：鏤空懸冕、從王冕散開的稀疏尖拱冷光、字形輪廓內的切角晶面、字符縫隙的斷續光階、小型星芒。
- **重要差異**：不再有整片盾形、高台面板、宴盤、橢圓、底部色塊或完整外框。深色體積來自每個字的斜向立體切面，不是從另一款作品搬來的底板。
- **動畫**：鏤空王冕上下微浮、筆畫內掃光、星芒明滅、各個光階錯時亮起。靜態 SVG 仍包含全部可見元素。

## 部署與檔案職責

`word/pride/` 一共 8 個檔案，完整保留舊檔名稱與全站共用 UI 接法：

- `index.html`：作品頁模板；共用作品頁 UI 由 `../shared/word_page.js` 建立。
- `pride.css`：本款透明棋盤格預覽舞台樣式；不變更網站整體色系。
- `pride_style.js`：作品標題、範例、生成器接線。
- `pride_template.js`：**本款唯一且獨立的全部 SVG 視覺構圖和動畫；此次真正重製的程式。**
- `pride.js`：直式 SVG、PNG、書封和預覽生成器。
- `pride_horizontal.js`：橫式 SVG、PNG、書封和預覽生成器。
- `pride_animated.js`：兩方向自足動態 SVG 的生成與下載。
- `README.md`：本款設計說明與驗收資訊。

## 規格

- 直式 SVG `840 × 1200`，PNG `1680 × 2400`。
- 橫式 SVG `1200 × 760`，PNG `2400 × 1520`。
- 書封 PNG `700 × 1000`，透明底。
- 直式與橫式動態 SVG 都包含完整藝術字、獨有構圖與裝飾。
- 支援 1～4 字，不因為是重製版而更改四個共用下載按鈕。
- 所有軍火庫函式經 `https://lib.stillnessbyslowly.com/` 絕對網址引入，不複製、內嵌軍火庫原始碼。
- HTML/CSS/JS 原始碼保持正常縮排及必要中文註解，沒有壓縮。
