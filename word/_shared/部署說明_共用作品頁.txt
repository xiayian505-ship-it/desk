【本包基底】
原始 word.zip + 已完成的逐鹿中原 v10、相濡以沫 v5、SVG 檢視室、黑羽舞動 v2，
最後覆蓋「word_home_viewer_titles_fix.zip」的標題與檢視室更新，

【覆蓋方式】
1. 解壓 ZIP。內有 word/ 資料夾。
2. 將 word/ 整個覆蓋到現有 desk 專案的 word/。
3. 依照你原本手機 Termux 的 Git 流程同步與推送。
4. GitHub Pages 更新後，逐頁點開 33 款作品（原 32 款 + 黑羽舞動）。

無。0 個。

不是遺留的重複 UI JS，不需刪除。
本包新增 word/_shared/word_page.js、word/_shared/README.md。
