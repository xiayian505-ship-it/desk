# 慢慢藝術字｜共用封面 v1

本封面用在 `word/index.html` 的 33 款藝術字目錄卡片，只是統一的**作品封面**，不取代各款生成器，也不聲稱展示實際 SVG 字體效果。

## 檔案分工

- `word_cover.js`：建立共用封面 DOM，從 `index_data.js` 的 `phrase`（若無則用 `title`）帶入文字。
- `word_cover.css`：紙色、框線、大小、字體、排版、裝飾、手機版。日後要磨封面優先改這裡。
- `word/index_style.js`：只負責把封面放進原本的作品卡片，並繼續控制 A～Z 分頁、搜尋及進入連結。
- `word/index_style.css`：只保留目錄卡片與首頁其餘介面，不再用 `data-visual` 提供每款不同色卡。

## 日後新增作品

只在 `word/index_data.js` 加入新作品資料，`phrase` / `title` 就會自動顯示在封面上。**不需要新建封面 CSS、JS，也不需要製作 33 張圖片。**

設計固定：每張封面的框線、配色、品牌字樣與裝飾相同，只有中央藝術字名稱不同。單字至四字會自動調整排版；多於四字時採每兩字一行。

封面不受單款藝術字的繪圖核心影響，沒有複製軍火庫程式碼，也沒有引入外部圖片或字型檔。首頁其他功能維持原樣。
