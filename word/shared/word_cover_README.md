# 慢慢藝術字｜共用封面 v2（極簡單行）

用於 `word/index.html` 的所有作品卡片。封面僅保留中央**一行作品名稱**及其後方的**斜置橢圓**，沒有品牌標記、雙層外框、上下分隔線或動畫特效。卡片下半部原有的英文名稱、中文名稱、專屬描述與進入連結完全不變。

## 檔案分工

- `word_cover.js`：建立共用封面 DOM，由 `index_data.js` 的 `phrase`（沒有時使用 `title`）帶入單行文字。
- `word_cover.css`：設定紙面顏色、橢圓線條、文字與手機版尺寸；想調整封面只需改這一份 CSS。
- `word/index_style.js`：沿用首頁既有的作品卡片組裝、A～Z 分頁、搜尋與連結。
- `word/index_style.css`：保留整體卡片及下半部資訊版面。

## 新增作品

在 `word/index_data.js` 加入一筆作品資料即可自動產生封面，不用逐款製作圖片、寫 HTML 或 CSS，也不依賴作品專屬 SVG 生成器。

本版不接 Shine Text 等特效，待實際看過 33 款的整體效果後再決定是否調整。
