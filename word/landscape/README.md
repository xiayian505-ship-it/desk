# 錦繡河山｜Landscape Lettering

- **主題**：主字不是一塊綠色字，而是一片被文字筆畫框住的山河；背景則是華美的錦繡絲線、菱花、金繡紋路。青山綠水與織錦同時存在。
- **配色**：遠山黛綠、近山松綠、江水青碧、薄霧乳白；織紋用暗金與淡金作點綴，不以金色取代青綠主體。
- **字體**：宋／明體厚重筆勢，筆畫內分層繪製山勢、河道、霧痕與織線；外有松墨描邊和錦金細邊。
- **字與字之間**：各字相互獨立，但山河材質相連；直式像山河長卷逐段展開，橫式像延綿山勢向遠方鋪開。
- **主題線條**：遠近山稜線藏在文字內部，江水從文字下半部蜿蜒穿行；不只是把山畫在文字外面。
- **元素點綴**：上下兩條金青交織菱花錦邊、側邊金線、金絲結、雲紋、藤葉與絲繡花朵，都是 SVG 本體裝飾，不是網頁背景圖。
- **動畫**：雲絲極輕流動、刺繡結微微擺動、金青絲點緩緩呼吸，動態 SVG 保留完整畫面且不依賴外部程式或 CSS。
- **文字**：1～4 字自適應，直式與橫式獨立構圖；使用者只輸入文字，配色固定。
- **下載**：SVG 840×1200／1200×760；透明 PNG 1680×2400／2400×1520；書封 PNG 700×1000；動態 SVG。四者皆以同一款獨立 SVG 圖像為基礎，輸出背景透明。
- **共用架構**：引用 `../shared/word_page.js` 和 `../word_style.css`；生成／PNG 模組以軍火庫正式 HTTPS 絕對 URL 載入，不在本款內複製。
- **入口**：`word/index_data.js` 的 `landscape`，頁面 `word/landscape/index.html`，歸 L 分類。

注意：中文字體使用觀看裝置上可用的宋／明體。未夾帶字型檔；不同裝置的實際筆畫輪廓可能不同。棋盤格只屬網站預覽輔助，不會進入輸出。
