# 羽翼生風｜慢慢藝術字（wings v2）

- 材質方向：飛揚白羽、碎半羽毛、飄落羽毛、淡紫偏光與輕盈風勢
- 元素點綴：大量高透明度白色實心羽毛，交錯疊滿視覺
- 路徑：`word/wings/index.html`
- 字數：1～4 字；直式 840×1200 SVG / 1680×2400 透明 PNG
- 橫式：1200×760 SVG / 2400×1520 透明 PNG
- 書封：700×1000 透明 PNG
- 動態：保留可下載的動態 SVG（SMIL）；普通 SVG / PNG 保持靜態
- 軍火庫：文字產生器、Canvas PNG、Blob URL、預覽 glow + lift 皆以 HTTPS 絕對網址引用
- 藝術字本體：改為 `wings_core.js` 獨立繪圖，不再依賴 `word_material_core.js`
- 無外部圖片或字型檔；所有羽毛、風線、偏光與文字材質都直接繪入 SVG
- 版權／字型授權說明在藝術字主頁統一管理

## 本次精修重點

1. 建立 `wings_core.js`，獨立處理直式、橫式與動態 SVG 輸出。
2. 主字改為白、淺白、紫、淺紫的羽毛質地字面，帶有局部炫彩偏光。
3. 字與字之間採交錯飛揚的錯位感，不使用死板固定角度。
4. 加入大量高透明度白色實心羽毛，包含完整羽毛與碎半羽毛。
5. 保留動態 SVG，讓羽毛與風線有輕盈飄動效果。
