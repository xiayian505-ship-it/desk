# 羽翼生風｜慢慢藝術字（wings v1）

- 材質方向：羽毛羽軸、柔白羽絨與輕盈飛舞
- 路徑：`word/wings/index.html`
- 字數：1～4 字；直式 840×1200 SVG / 1680×2400 透明 PNG
- 橫式：1200×760 SVG / 2400×1520 透明 PNG
- 書封：700×1000 透明 PNG
- 動態：另外提供可下載的動態 SVG（SMIL）；普通 SVG/PNG 保持靜態。
- 軍火庫：文字產生器、Canvas PNG、Blob URL 以 HTTPS 絕對網址引用，預覽搭配 glow + lift CSS 原函式。
- 局部 SVG 材質、紋理圖騰和動態由 `word_material_core.js` 渲染，設定在 `wings_template.js`；無外部圖片或字型檔。
- 版權／字型授權說明在藝術字主頁統一管理。

## 注意

新系列共用 `word/word_material_core.js`（本次 ZIP 附帶），請務必一起部署。
