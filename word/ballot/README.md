# 投我一票｜Ballot Lettering

- **主題**：有點吵、有點可愛、讓人想投它一票的卡通競選風。不是正式選舉宣傳物。
- **配色**：高飽和鮮黃色與芒果橘作主字；深紫墨描邊、莓粉與薄荷青做對比點綴。
- **字體**：圓潤粗胖漫畫字，字與字的傾斜角度略不同；外有極粗深紫邊、錯位橙紫立體陰影與亮白弧形高光。
- **字間關係**：四字並列或直列時都有微微歪斜的跳動節奏，1～4 字縮放並重新分配字位；直橫式各自安排字形與道具，不旋轉畫布。
- **裝飾元素**：可愛笑臉投票箱、飛出的打勾選票、勾選貼紙、漫畫爆炸星、彩紙與前進動勢線，均是獨立 SVG 圖層。
- **動畫**：主字依次輕彈、選票上下浮動、票箱搖晃、星星轉動，彩紙緩慢搖擺；自足動態 SVG 不靠網頁特效。
- **輸入**：繁體中文或英文皆可，1～4 個 Unicode 字素，文字內容可替換，色彩與視覺由本款固定控制。
- **匯出**：直式 SVG 840×1200／PNG 1680×2400；橫式 SVG 1200×760／PNG 2400×1520；書封 PNG 700×1000；直橫動態 SVG；畫布透明，所有裝飾一併下載。
- **網站**：共用 `../shared/word_page.js` 與 `../word_style.css`，外接軍火庫正式 HTTPS 文字生成器和 PNG 下載元件，不複製軍火庫程式。
- **主頁**：`word/index_data.js` 新增 `ballot`，依英文首字母 B 分類。

注意：作品字型採裝置可用的圓潤粗黑／黑體備援；沒有內嵌字型檔。跨裝置字形會有細微差異。透明棋盤格只存在於網頁預覽，不包含在下載檔中。
