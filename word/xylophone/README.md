# 輕音流轉｜慢慢藝術字（xylophone v2）

- 材質方向：柔霧旋律線、淡木紋光澤、暖金邊與貼字流動的音符點綴
- 路徑：`word/xylophone/index.html`
- 字數：1～4 字；直式 840×1200 SVG / 1680×2400 透明 PNG
- 橫式：1200×760 SVG / 2400×1520 透明 PNG
- 書封：700×1000 透明 PNG
- 動態：提供可下載的動態 SVG（音符、旋律線與字內光澤會緩慢流動）；普通 SVG/PNG 保持靜態。
- 軍火庫：文字產生器、Canvas PNG、Blob URL 以 HTTPS 絕對網址引用。
- 本款已改為獨立核心：`xylophone_core.js` 負責專屬構圖、音符、旋律線與動態，不再依賴 `word_material_core.js`。
- 無外部圖片或字型檔；透明背景，所有材質、旋律線與裝飾皆由 SVG 程式生成。

## 說明

本次精修參考霧光流線的氣質，把原先木質音條感調整成更輕、更流動的版本。
主題字仍保留溫潤木質與暖金邊，但把視覺重心拉到「旋律」本身：
一條貼著字流動的柔光旋律線，配上小型音符與微光點綴，讓畫面更接近「輕音流轉」。
