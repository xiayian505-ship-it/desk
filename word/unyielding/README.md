# 寧折不彎｜慢慢藝術字

- 系列代號：`unyielding`
- 建議路徑：`word/unyielding/`
- 系列名稱：寧折不彎
- 代表文字：寧折不彎
- 字數限制：1～4 字
- 排列方式：直式、橫式
- 下載格式：SVG、動態 SVG、透明 PNG、700 × 1000 書封 PNG
- 背景：透明

## 視覺重點

- 黑鐵冷光立體字
- 筆畫硬直，不做柔軟彎曲感
- 裂痕與斷面沿字體本身展開
- 上一個字的尾巴，部分壓在下一個字的頭上
- 交疊處有應力裂紋、壓痕與微碎屑
- 整體維持挺立、不屈

## 接入說明

本系列沿用慢慢藝術字共用宿主介面：

- `index.html`
