# 琉璃幻彩｜慢慢藝術字（crystal v2）

**精修版：獨立 SVG 繪圖模板，不再使用共用材質核心。**

- 路徑：`word/crystal/index.html`，保留全系列 `word/shared/word_page.js` 共用作品頁。
- 意象：水晶、琉璃、鏡面折射、晶體切面；冰藍／淺藍／白／靛色／淺青／紫羅蘭炫彩漸層。
- 橫式：四字沿向上的彩虹拱形（∩）錯落排版，字距偏緊，字形各自輕微轉角。
- 直式：字體不轉成側躺，僅位置沿側向的彩虹拱形排列；字形正向且各自微調角度。
- 1～4 字：各字數有對應構圖，晶片點綴依實際字形位置生成。
- SVG 本體：每字的透明鏡面層、幾何晶面、折射打光、亮緣和文字下方三角形晶片全部在 SVG 裡；點綴三角形不透明度為 20%～40%，不蓋過文字。
- 直式：840 × 1200 靜態 SVG；1680 × 2400 透明 PNG。
- 橫式：1200 × 760 靜態 SVG；2400 × 1520 透明 PNG。
- 書封：700 × 1000 透明 PNG，完整作品按比例置入。
- 動態：本次未新增動畫；動態 SVG 按鈕由共用頁維持停用。
- 軍火庫：原本的文字生成器、Canvas PNG、Blob URL、網站預覽 Glow／Lift，仍以 HTTPS 絕對路徑引用；不複製軍火庫函式。
- 字型：以系統合法可用的繁體中文襯線字體優先，未夾帶字型檔。

## 檔案分工

- `crystal_template.js`：本款獨立 SVG，實際字體材質及三角形點綴。
- `crystal.js`、`crystal_horizontal.js`：直橫式字數構圖和下載生成器。
- `index.html`：本款預覽框和 script 引用，已移除 `../word_material_core.js` 依賴。
- 其他 CSS、`crystal_style.js`：維持作品頁設定、既有預覽外觀和軍火庫引用。

不改動全系列共用 UI、其他作品或全系列 `word_readme.md`。
