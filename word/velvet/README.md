# 絲絨華彩｜慢慢藝術字（velvet v2）

- 材質方向：酒紅絲絨、細密絨絲、柔亮緞光、靜態偏光
- 元素點綴：白色圓形襯衫鈕扣 3 顆，作為服飾感細節
- 路徑：`word/velvet/index.html`
- 字數：1～4 字；直式 840×1200 SVG / 1680×2400 透明 PNG
- 橫式：1200×760 SVG / 2400×1520 透明 PNG
- 書封：700×1000 透明 PNG
- 動態：本次精修維持靜態；共用頁第 4 個按鈕保留但停用
- 軍火庫：文字產生器、Canvas PNG、Blob URL、預覽 glow + lift 皆以 HTTPS 絕對網址引用
- 藝術字本體：改為 `velvet_core.js` 獨立繪圖，不再依賴 `word_material_core.js`
- 無外部圖片或字型檔；所有絲絨質感、偏光、緞光與鈕扣都直接繪入 SVG
- 版權／字型授權說明在藝術字主頁統一管理

1. 建立 `velvet_core.js`，獨立處理直式與橫式輸出。

3. 以 SVG 多層漸層與柔光矩形做靜態偏光效果。
4. 加入 3 顆白色圓形襯衫鈕扣，強化服飾與可觸摸感。
5. 保留共用作品頁、下載流程與透明輸出規格。
