# 御駕親征｜Imperial Lettering

- **主題**：帝王親征、御前軍令、出師旌旗；肅穆而非宮廷裝飾品。
- **主色**：明皇黃 `#FFB61E`，配鎏金高光、玄黑雕漆邊、朱紅軍旗。
- **字體**：宋體／明體系統字族，主字金色漸層、暗黑雕邊與朱紅細輪廓；字形不添加外部字型檔。
- **字間與動勢**：各字獨立居中且微微錯位，像排列於軍令旗上的金字；1～4 字分別校正字級、位置與留白。
- **主題線條**：兩道不透明度不同的橢圓御環、上下金印紋、長槍；主字在裝飾上方保持清楚可讀。
- **點綴**：手繪朱紅鎏金旌旗、蜿蜒龍雲紋、金塵與軍令印璽；全部屬於 SVG，可隨作品匯出。
- **橫式**：重新安排旗、御環、字距、龍紋與金線，不旋轉直式。
- **動畫**：旌旗緩揚、文字金色流轉、金塵呼吸；動態 SVG 自足，可離線播放。靜態 SVG／PNG／書封不含動畫，但包含全套裝飾。
- **共用架構**：本款不重寫操作界面，沿用 `../shared/word_page.js`、`../word_style.css`；軍火庫原件皆以 HTTPS 絕對網址引用。
- **尺寸**：直式 840×1200／PNG 1680×2400；橫式 1200×760／PNG 2400×1520；書封 700×1000，透明背景。
- **入口**：首頁 `index_data.js` 的 `imperial` 資料筆與作品資料夾 `word/imperial/`。

> 注意：SVG 文字字型會使用觀看裝置已安裝的宋體或明體系統字型。不同裝置、特別是沒有中文字型的環境，筆畫造形可能不同。本系列沿用現行字型策略，沒有夾帶字型檔。
